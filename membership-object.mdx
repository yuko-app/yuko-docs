---
title: "Membership Object"
description: "Fields returned for a customer's loyalty membership summary by the Yuko REST API."
---

The membership object summarizes a customer's standing in your loyalty program: points balance, current VIP tier, next tier and progress toward it. It's returned by [Get customer membership](/developer/api/list-memberships) (`GET /public/customers/memberships`, scope `customers` read).

<Note>
This object describes loyalty program membership. Paid membership plans (Membership → Plans) aren't available through the REST API.
</Note>

**status**

**string**

The customer's membership status. Always `active` for a customer returned by this endpoint.

Example:

`"active"`

**member_since**

**string\<date-time\>**

When the customer was added to Yuko (ISO 8601).

Example:

`"2025-11-02T10:15:00+00:00"`

**points**

**object**

The customer's points summary.

**points.balance**

**integer**

The customer's spendable points balance. Always `0` for a customer who is excluded from the loyalty program.

Example:

`650`

**points.earned**

**integer**

Total points the customer has earned.

Example:

`1200`

**points.redeemed**

**integer**

Total points the customer has redeemed.

Example:

`550`

**current_tier**

**object | null**

The customer's current VIP tier, or `null` if VIP tiers are turned off or the customer hasn't reached a tier. Contains:

- `id` (string, UUID)
- `name` (string)
- `threshold_value` (integer): the value needed to reach the tier
- `multiplier` (number): the tier's points multiplier, `1` when none is set
- `icon` (object | null)
- `benefits` (array of objects with `name`, `benefit_type` and `benefit_value`)
- `created_at` (string, date-time)

**next_tier**

**object | null**

The next VIP tier the customer can reach, with the same fields as `current_tier`. `null` if VIP tiers are turned off or the customer is already at the highest tier.

**progress_to_next_tier**

**object | null**

The customer's progress toward `next_tier`, or `null` if VIP tiers are turned off or there's no next tier. Contains:

- `current_value` (integer): the customer's current qualifying value
- `required_value` (integer): the value needed for the next tier
- `remaining_value` (integer): how much more is needed
- `progress_percentage` (number): progress as a percentage
- `threshold_type` (string): the metric used for tier progression
