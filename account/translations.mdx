## Introduction

Translations lets you show Yuko's customer-facing text in each language your store sells in. You can translate system labels, such as activity entries and points wording, and your own dynamic content, such as campaign and reward names.

Which languages appear here is managed in your Shopify store settings. Yuko shows one tab for each language your store publishes.

## When to use

- Your store publishes more than one language in Shopify.
- You want campaign names, reward names and tier descriptions to read naturally in each language.
- You want the customer activity history to use your own wording.

## Overview

- **Language tabs**: one per published store language. Your default language is marked **(default)**. Extra languages appear under **More languages** when there isn't room.
- **Content groups**: General, Points & Earning, Rewards, Campaigns, Booster Campaigns, VIP Tiers, Membership, Activity and Referral. Groups only appear when they have content to translate.
- **Editor**: each row shows the **Default** text on the left and a **Translation** field on the right. Empty fields show the default text as a placeholder.
- **Reset content**: clears every translation in the selected group for the selected language.

## Before you start

<Check>The languages you need are published in Shopify (**Settings → Languages**).</Check>
<Check>Your campaigns, rewards, tiers and other content are set up in your default language.</Check>

## Setup

<Steps>
  <Step title="Open Translations">
    Go to **Apps → Yuko Loyalty → Account → Translations**.
  </Step>
  <Step title="Pick a language">
    Select the language tab you want to translate into.
  </Step>
  <Step title="Pick a group">
    Select a group, such as **Campaigns** or **Rewards**.
  </Step>
  <Step title="Enter translations">
    Type the translation next to each default text. A translation can't be saved empty.
  </Step>
  <Step title="Save">
    Click **Save** in the save bar. Changes in every group of the selected language are saved together. Save each language separately before you move on to the next one.
  </Step>
</Steps>

## How it works

- Shoppers see the translation for the language they're browsing your store in. Text without a translation falls back to your default language.
- On the default language tab, only the **Activity** group is shown, so you can change the wording of activity entries in your main language. Other default-language text is edited where you create it, such as in the campaign or reward.
- **Reset content** asks you to confirm with **Clear all**. It removes every translation override for that group in that language, and shoppers using that language then see the default-language text. This can't be undone.
- Widget text, such as headings and button labels in Floating Rewards or the cart widgets, is translated in each widget's editor using its **Editing language** picker. See [Branding and locale](/onsite-widgets/branding-and-locale).

## Best practices

<Tip>**Finish your default-language content first.** New campaigns and rewards appear here once they exist.</Tip>
<Tip>**Translate high-visibility groups first:** Campaigns, Rewards and VIP Tiers are what shoppers see most.</Tip>
<Tip>**Revisit after changes.** When you add a new campaign or reward, add its translations too.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="Why do I only see one language?">
    Your Shopify store publishes only one language. Add and publish another language in Shopify, then come back to Translations.
  </Accordion>
  <Accordion title="Why does a language tab say there's no content to translate?">
    There's nothing in that language that needs translating yet. Create campaigns, rewards or other content first.
  </Accordion>
  <Accordion title="Can I undo Reset content?">
    No. Clearing a group removes its translations for that language permanently. You'll need to enter them again.
  </Accordion>
</AccordionGroup>
