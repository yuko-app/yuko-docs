---
title: "Points Transaction Object"
description: "Fields returned for a points transaction by the Yuko REST API."
---

A points transaction is a ledger entry that changes a customer's points balance. Points added are a `credit`; points removed are a `debit`. Transactions are returned by [List points transactions](/developer/api/list-points-transactions) (`GET /public/customers/transactions`, scope `transactions` read). You can add or deduct points with [Create a points transaction](/developer/api/create-a-points-transaction) (`POST /public/customers/transactions`, scope `transactions` write).

**id**

**string\<uuid\>**

Unique identifier for the points transaction.

Example:

`"b2c3d4e5-f6a1-7890-bcde-f01234567890"`

**customer_id**

**string\<uuid\>**

Yuko's internal UUID for the customer whose balance changed. This is not the Shopify customer ID you pass as the `customer_id` parameter.

Example:

`"63a2c89a-9936-4bc0-9d5f-93db46110b76"`

**entry_type**

**enum\<string\>**

Whether points were added or removed.

Available options:

`credit`,

`debit`

Example:

`"credit"`

**points**

**integer**

The number of points added or removed. Always positive; use `entry_type` for the direction. For the `store_credit` credit entry recorded when a customer redeems a store credit reward, this is the store credit amount (rounded down to a whole number) rather than points.

Example:

`100`

**action_type**

**string**

The action that created the transaction, for example `purchase`, `point_adjustment` (manual and REST API adjustments) or the reward type for redemptions.

Example:

`"purchase"`

**status**

**enum\<string\>**

The current status of the transaction.

Available options:

`active`,

`on_hold`,

`used`,

`failed`

Example:

`"active"`

**description**

**string | null**

A description of the change, if one was provided.

Example:

`"Points correction"`

**source**

**string | null**

Where the transaction came from. Transactions created through the REST API have the source `rest_api`.

Example:

`"rest_api"`

**transacted_at**

**string\<date-time\> | null**

The date and time the transaction took effect (ISO 8601).

Example:

`"2026-02-15T08:30:00+00:00"`

**created_at**

**string\<date-time\>**

The date and time the transaction record was created (ISO 8601).

Example:

`"2026-02-15T08:30:00+00:00"`
