---
title: "Points Transaction Object"
description: "Fields returned for a points transaction by the Yuko REST API."
---

A points transaction is a ledger entry that changes a customer's points balance. Points added are a `credit`; points removed are a `debit`. Transactions are returned by [List points transactions](/developer/api/list-points-transactions) (`GET /public/customers/transactions`, requires the `read:transactions` scope). You can add or deduct points with [Create a points transaction](/developer/api/create-a-points-transaction) (`POST /public/customers/transactions`, requires the `write:transactions` scope).

## Properties

<ResponseField name="id" type="string<uuid>">
  Unique identifier for the points transaction.
</ResponseField>

<ResponseField name="customer_id" type="string<uuid>">
  Yuko's internal UUID for the customer whose balance changed. This is not the Shopify customer ID you pass as the `customer_id` parameter.
</ResponseField>

<ResponseField name="entry_type" type="enum<string>">
  Whether points were added or removed. One of `credit`, `debit`.
</ResponseField>

<ResponseField name="points" type="integer">
  The number of points added or removed. Always positive; use `entry_type` for the direction. For the `store_credit` credit entry recorded when a customer redeems a store credit reward, this is the store credit amount (rounded down to a whole number) rather than points.
</ResponseField>

<ResponseField name="action_type" type="string">
  The action that created the transaction, for example `purchase`, `point_adjustment` (manual and REST API adjustments) or the reward type for redemptions.
</ResponseField>

<ResponseField name="status" type="enum<string>">
  The current status of the transaction. One of `active`, `on_hold`, `used`, `failed`.
</ResponseField>

<ResponseField name="description" type="string | null">
  A description of the change, if one was provided.
</ResponseField>

<ResponseField name="source" type="string | null">
  Where the transaction came from. Transactions created through the REST API have the source `rest_api`.
</ResponseField>

<ResponseField name="transacted_at" type="string<date-time> | null">
  The date and time the transaction took effect (ISO 8601).
</ResponseField>

<ResponseField name="created_at" type="string<date-time>">
  The date and time the transaction record was created (ISO 8601).
</ResponseField>
