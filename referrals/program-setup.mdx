## Introduction

The **Program** tab is where you configure the whole referral program: rewards for both sides, where referral links land, which sharing channels customers see, and how Yuko blocks fraudulent referrals.

## What problem this solves

Running referrals usually means combining a referral app, a discount tool and a tracking setup. The Program tab covers all three. Yuko creates the Shopify discount codes, tracks referral links with a UTM campaign, and checks every claim against your fraud rules.

## When to use

- When you launch the referral program.
- When you change reward values or sharing channels.
- When you want to tighten fraud controls.

## Overview

The Program tab has these sections:

| Section | What it controls |
|---|---|
| **Referrals Program Status** | Turns the program on or off. |
| **Quick Start** | Setup checklist: **Set up referrer reward**, **Set up friend reward**, **Enable referral popup**. |
| **Referral Rewards** | The **Referrer Reward** and the **Friend Reward**. |
| **Referrals Landing URL** | The page a referral link opens. |
| **Social Sharing Settings** | Which share channels customers see, and the pre-filled messages. |
| **Fraud Prevention** | **IP Address Match** and **Block Self-Referrals**. |
| **Auto Enrollment** | **Enroll on first point earned**. |
| **UTM Tracking** | The **UTM Campaign** value added to referral links. |

## Setup guide

### 1. Turn on the program

<Steps>
  <Step title="Open the Program tab">
    In your Shopify admin, go to **Apps → Yuko Loyalty → Referral → Program**.
  </Step>
  <Step title="Enable the program">
    In **Referrals Program Status**, switch the toggle on. The card shows "This program is currently enabled". If you later switch it off, Yuko asks you to confirm in a **Disable Referrals Program** dialog.
  </Step>
</Steps>

### 2. Set up the rewards

<Steps>
  <Step title="Choose the referrer reward">
    In **Referral Rewards**, click **Add Reward** on the **Referrer Reward** card (or **Change Reward** to replace the current one). Pick a reward type and fill in the configuration page. See [Reward Types](/referrals/reward-types).
  </Step>
  <Step title="Choose the friend reward">
    Do the same on the **Friend Reward** card.
  </Step>
</Steps>

<Info>
On a new install, Yuko seeds both rewards as a fixed $10 amount discount: "Referral reward" (coupon prefix `YRA`) for the referrer and "Welcome reward" (coupon prefix `YRF`) for the friend. Change them to suit your store.
</Info>

### 3. Set the landing URL

<Steps>
  <Step title="Enter a path">
    In **Referrals Landing URL**, fill in **Referrals Landing URL Path**, for example `/collections/best-sellers` or `/pages/welcome`. If you leave it blank, referral links open your homepage.
  </Step>
</Steps>

### 4. Choose the sharing channels

<Steps>
  <Step title="Tick the channels">
    In **Social Sharing Settings**, tick the channels customers can share through: **Twitter**, **Facebook**, **Email** and **Whatsapp**.
  </Step>
  <Step title="Write the pre-filled messages">
    Each ticked channel shows its message fields:
    - **Twitter**: **Message to tweet**
    - **Email**: **Email Subject** and **Email Body**
    - **Whatsapp**: **Message to Whatsapp**

    Use `[shop_name]` for your store name and `[referral_link]` for the customer's referral link. The Email Subject supports `[shop_name]` only.
  </Step>
</Steps>

<Note>
Facebook doesn't let third-party apps pre-fill share messages, so there's no message field for Facebook. Customers write their own message when they share.
</Note>

### 5. Configure fraud prevention

<Steps>
  <Step title="Block Self-Referrals">
    Stops customers from using their own referral link. It's **on by default**. Yuko blocks the claim when the friend's email matches the referrer's, or when the friend resolves to the same Shopify customer as the referrer.
  </Step>
  <Step title="IP Address Match">
    Blocks the claim when the friend and the referrer share the same IP address. This toggle is available on select plans.
  </Step>
</Steps>

### 6. Configure auto enrollment

<Steps>
  <Step title="Enroll on first point earned">
    Turn this on to enroll a customer in the referral program automatically the first time they earn loyalty points. Enrolled customers get a referral code and link without having to request one.
  </Step>
</Steps>

Customers who aren't enrolled can still join by clicking **Get my referral link** in a referral widget.

### 7. Set the UTM campaign

<Steps>
  <Step title="Enter the UTM Campaign">
    In **UTM Tracking**, set **UTM Campaign**. This is the `utm_campaign` value added to every referral link. If you leave it empty, Yuko uses `yuko_referral_program`.
  </Step>
</Steps>

Only the campaign value is configurable. A referral link looks like this:

```
https://your-store.com/<landing path>?yuko_referral=<CODE>&utm_campaign=yuko_referral_program
```

### 8. Save

Click **Save** in the save bar.

## How it works

1. A customer becomes a referrer, either automatically (if **Enroll on first point earned** is on) or by clicking **Get my referral link** in a referral widget. Yuko gives them a unique referral code and link.
2. The referrer shares the link through a widget or one of the enabled channels.
3. A friend opens the link. The **Friend Welcome Popup** asks for their details (at least an email).
4. Yuko checks the claim:
   - The referral code is valid and the referrer isn't blocked.
   - **Block Self-Referrals** and **IP Address Match** rules pass (when turned on).
   - The friend has no previous orders and hasn't already received a friend reward.
5. If the claim passes, Yuko creates the friend's discount code and shows it in the popup.
6. When the friend places a paid order using that code, Yuko issues the referrer reward and counts the referral as successful.

### Limitations

- The referrer is rewarded only for a paid order that uses the friend's referral discount code.
- Friends must be new customers. A friend with an existing order can't claim a friend reward.
- Each customer can receive only one friend reward.
- Referral links rely on the `yuko_referral` URL parameter, so the friend must open the full link.

## Examples

- Referrer gets 500 points (**Earn Points**); friend gets $10 off (**Amount Discount**), with **Block Self-Referrals** and **IP Address Match** on.
- Referrer gets $20 **Store Credit**; friend gets 15% off (**Percentage Off**), with the landing URL set to `/collections/best-sellers`.

## Best practices

<Tip>**Test the whole flow before you promote it.** Share a link, open it in a private window, claim the friend reward, place an order with the code, and check that the referrer is rewarded.</Tip>
<Tip>**Keep Block Self-Referrals on.** It's the main guard against customers rewarding themselves.</Tip>
<Tip>**Promote referrals in your post-purchase moments.** The Post-Purchase Widget and your order emails reach customers when they're most engaged.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="When is the referrer rewarded?">
    When the friend places a paid order that uses the friend's referral discount code. Orders without that code don't count as referral orders.
  </Accordion>
  <Accordion title="Can a referrer refer themselves?">
    Not while **Block Self-Referrals** is on. Yuko blocks claims where the friend's email or Shopify customer matches the referrer. Turn on **IP Address Match** too if you want to block claims from the referrer's IP address.
  </Accordion>
  <Accordion title="Can I add utm_source or utm_medium to referral links?">
    No. Only **UTM Campaign** is configurable.
  </Accordion>
  <Accordion title="Where do customers find their referral link?">
    In the referral widgets (the Post-Purchase Widget and the Referral Landing Page), and in the referral sections of the Floating Rewards launcher and the customer account page. See [Referral widgets](/referrals/widget).
  </Accordion>
</AccordionGroup>
