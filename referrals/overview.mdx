## What is the Referral Program

The Referral Program lets your customers (referrers) share a personal link with friends. Both sides get rewarded:

- The **friend** gets a welcome reward (a discount code) when they open the link and enter their details.
- The **referrer** gets their reward once the friend places a paid order using that discount code.

It isn't a separate app. Referrals sit alongside your loyalty program and use the same customers, points balance and storefront widgets.

## Who it's for

- Brands with strong word of mouth that want to make it repeatable.
- High-AOV or considered-purchase stores, where a personal recommendation carries weight.
- Stores that want to lower acquisition costs by rewarding existing customers.

## The Referral menu

The **Referral** section of the Yuko admin has three tabs:

| Tab | What you do there |
|---|---|
| **Program** | Turn the program on, set the referrer and friend rewards, and configure the landing URL, social sharing, fraud prevention, auto enrollment and UTM tracking. See [Program Setup](/referrals/program-setup). |
| **Widgets** | Configure the storefront and post-purchase referral widgets. See [Referral widgets](/referrals/widget). |
| **Emails** | Edit the referral emails. See [Referral emails](/emails/referral-emails). |

## How it fits together

```
Referrer gets a referral link  ─→  Shares it  ─→  Friend opens the link
                                                         │
                                                         ▼
                                     Friend Welcome Popup: friend enters email
                                                         │
                                                         ▼
                                     Friend gets a discount code (friend reward)
                                                         │
                                                         ▼
                                     Friend places a paid order with that code
                                                         │
                                                         ▼
                        Referrer gets their reward (discount, points or store credit)
```

The referrer reward and the friend reward are set separately, so you can pick what suits each side. See [Reward Types](/referrals/reward-types).

## Get started

<Steps>
  <Step title="Set up both rewards">
    Open **Referral → Program**. The **Quick Start** card walks you through **Set up referrer reward**, **Set up friend reward** and **Enable referral popup**.
  </Step>
  <Step title="Review the program settings">
    Check the landing URL, sharing channels and fraud prevention in [Program Setup](/referrals/program-setup).
  </Step>
  <Step title="Turn on the widgets">
    Enable the **Friend Welcome Popup** so friends can claim their reward, then add a way for customers to get their link, such as the **Post-Purchase Widget** or the **Referral Landing Page**. See [Referral widgets](/referrals/widget).
  </Step>
</Steps>
