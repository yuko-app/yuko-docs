## Introduction

The Shopify Flow integration sends Yuko events to [Shopify Flow](https://apps.shopify.com/flow) as workflow triggers. Anything Flow can do next, such as tagging a customer, notifying staff or updating a metafield, can run when a customer earns points, moves up a VIP tier or completes a referral.

Each trigger carries the customer's loyalty profile plus details about the event, so you can use them in Flow conditions and actions.

Yuko also adds one Flow **action**, **Yuko Add Points for Review**, which lets other reviews apps award points through your **Write a review** earn rule.

## When to use

- You already automate your store with Shopify Flow.
- You want loyalty events to drive Shopify-native actions (customer tags, staff alerts, metafields).
- You use a reviews app other than Judge.me and want reviews to earn loyalty points.

## Before you start

<Check>Shopify Flow is installed on your store.</Check>
<Check>Yuko is installed and your loyalty program is enabled.</Check>

## Set up the triggers

<Steps>
  <Step title="Enable the integration">
    In Yuko, go to **Apps → Yuko Loyalty → Integrations → Shopify Flow** and switch the toggle on. The status badge changes to **Enabled**.
  </Step>
  <Step title="Choose the events to send">
    In the **Events** section, select the Yuko events you want to send to Shopify Flow, then click **Save Events**. Only selected events are sent.
  </Step>
  <Step title="Build a workflow in Shopify Flow">
    In Shopify admin, open **Shopify Flow**, create a workflow and pick a Yuko trigger, for example **Yuko VIP Tier Upgrade**. Add conditions and actions as usual, then turn the workflow on.
  </Step>
  <Step title="Send test events (optional)">
    Back in Yuko, click **Send Test Events** to send sample data for the selected events, so you can check your workflows.
  </Step>
</Steps>

## Available triggers

| Shopify Flow trigger | Event in Yuko | Fires when |
|---|---|---|
| **Yuko Loyalty Program Joined** | Joined Loyalty Program | A customer joins the loyalty program. |
| **Yuko Loyalty Earn Reward** | Earn Points | A customer earns loyalty points. |
| **Yuko Loyalty Redeem Points** | Redeem Points | A customer redeems points for a reward. |
| **Yuko Reward Expiring** | Reward Expiry Reminder | A redeemed reward is about to expire. |
| **Yuko Points Expiring** | Points Expiring Reminder | A customer's points are about to expire. |
| **Yuko Loyalty Birthday Reminder** | Birthday Reminder | A customer's birthday is coming up and your Birthday earn rule is active. |
| **Yuko Loyalty Anniversary Reminder** | Anniversary Reminder | A customer's loyalty anniversary is coming up and your Anniversary earn rule is active. |
| **Yuko VIP Tier Entry** | VIP Tier Entry | A customer enters a VIP tier for the first time. |
| **Yuko VIP Tier Upgrade** | VIP Tier Upgrade | A customer moves up to a higher VIP tier. |
| **Yuko VIP Tier Downgrade** | VIP Tier Downgrade | A customer drops to a lower VIP tier. |
| **Yuko Referral Friend Reward Claimed** | Friend reward unlocked | A referred friend claims their reward. |
| **Yuko Referral Completed** | Referral Completed | A referral is completed. |
| **Yuko Referral Advocate Rewarded** | Referrer Rewarded | The referrer receives their reward. |

## The Add Points for Review action

If your reviews app can trigger Shopify Flow, use the **Yuko Add Points for Review** action to award review points. Each run counts as a published review and earns points through your [Write a review](/loyalty/ways-to-earn/write-a-review) earn rule.

| Field | What to map |
|---|---|
| **Customer identifier** | The reviewer's customer ID or email from your reviews app's trigger. |
| **Product ID** | The Shopify product ID of the reviewed product. |
| **Photo Url** | The review's photo URL. If it has a value, the review also earns the media bonus when **Enable Media Earning** is on. |

<Steps>
  <Step title="Turn on Write a review">
    Enable the **Write a review** earn rule in Yuko and set the points.
  </Step>
  <Step title="Create the Flow workflow">
    In Shopify Flow, start with your reviews app's "review created" (or similar) trigger.
  </Step>
  <Step title="Add the Yuko action">
    Add the **Yuko Add Points for Review** action and map the three fields from the trigger.
  </Step>
  <Step title="Turn on the workflow">
    New reviews now earn loyalty points.
  </Step>
</Steps>

The action needs a customer and a product that already exist in Yuko; otherwise the run fails. Points are awarded once per customer per product, and the media bonus once.

<Info>Using Judge.me? Use the [Judge.me integration](/integrations/judgeme) instead. It connects directly without Shopify Flow.</Info>

## Example use cases

- **Tag VIPs:** **Yuko VIP Tier Upgrade** → condition on `yuko_new_tier_name` → add a customer tag such as `vip-gold`.
- **Points expiry outreach:** **Yuko Points Expiring** → condition on `yuko_points_at_risk` → send an internal email to your retention team.
- **Birthday prep:** **Yuko Loyalty Birthday Reminder** → add a `birthday-this-month` tag for a store-wide campaign.
- **Referral alert:** **Yuko Referral Completed** → condition on `yuko_friend_order_total` → notify staff in Slack.

## Limitations

- **Selected events only.** Yuko sends only the events you selected and saved.
- **Shopify Flow limits apply.** Flow has its own run limits; see Shopify's documentation.
- **Review points need a supported app.** The Add Points for Review action works with any reviews app that triggers Shopify Flow and exposes the customer, product and photo fields.

## Best practices

<Tip>**Use Flow for Shopify-native side effects** (tags, metafields, staff notifications). Use [Yuko Workflows](/workflows/overview) for loyalty-side automations such as emails, WhatsApp messages and points.</Tip>
<Tip>**Don't duplicate logic in both tools.** Pick one home for each automation.</Tip>
<Tip>**Send test events before going live** so you can check field mappings in Flow.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="How is this different from Yuko Workflows?">
    Yuko Workflows are loyalty-native (emails, WhatsApp, points, coupons). Shopify Flow is Shopify-native (tags, orders, staff alerts). Use each for what it does best.
  </Accordion>
  <Accordion title="Why isn't my Flow workflow firing?">
    Check that the Shopify Flow integration is **Enabled** in Yuko, that the event is selected under **Events** and saved, and that the Flow workflow is turned on.
  </Accordion>
  <Accordion title="Do I need to enable the integration to use the Add Points for Review action?">
    The action comes with the Yuko app in Shopify Flow. It needs the **Write a review** earn rule to be active so the review can earn points.
  </Accordion>
</AccordionGroup>
