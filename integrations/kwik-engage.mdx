## Introduction

[Kwik Engage](https://www.kwikengage.ai) is a WhatsApp Business API provider with strong India-region coverage. Once connected, the [WhatsApp Workflow node](/workflows/whatsapp-node) can send Kwik Engage templates — with or without dynamic CTA buttons — on any loyalty event.

For the provider-agnostic overview, see [WhatsApp](/integrations/whatsapp).

## When to use Kwik Engage

- You operate primarily in India and want a regional WhatsApp Business API provider.
- Your templates include **CTA buttons** with dynamic URL placeholders.
- You want to keep template variables and CTA URL variables on separate configuration tracks.

## Before you start

<Check>You have an active Kwik Engage account with WhatsApp Business API.</Check>
<Check>You have at least one **approved** Kwik Engage template.</Check>
<Check>You have your Kwik Engage API endpoint URL and API key.</Check>

## Connect Kwik Engage to Yuko

<Steps>
  <Step title="Get your Kwik Engage API key">
    Log in to Kwik Engage → **Settings → API**. Copy the API key and note the API endpoint URL.
  </Step>
  <Step title="Open Kwik Engage in Yuko">
    In Shopify admin, go to **Apps → Yuko Loyalty → Integrations → Kwik Engage**.
  </Step>
  <Step title="Paste the API key and Connect">
    Paste the key and click **Connect**. The tile flips to **Connected**.
  </Step>
  <Step title="Add a Kwik Engage step to a workflow">
    Open any workflow, click **+**, pick **WhatsApp**, and select **Kwik Engage** in the provider dropdown.
  </Step>
</Steps>

## Configure the Kwik Engage step in a workflow

Kwik Engage splits body parameters from CTA button parameters — toggle CTA buttons on only if your approved template has them.

| Field | What it is | Example |
|---|---|---|
| **Endpoint URL** | Kwik Engage API endpoint URL | `https://api.kwikengage.ai/...` |
| **Template Name** | Template identifier (no spaces) | `points_expiring_soon` |
| **Language Code** | Template language | `en_US` or `hi_IN` |
| **Parameter Count** | Number of body variables (1–25) | `2` |
| **Template Parameters** | One value per body variable — supports [shortcodes](/workflows/whatsapp-node#available-shortcodes) | `{{first_name}}`, `{{points_balance}}` |
| **Add CTA Button** *(toggle)* | Enable if the template has dynamic URL buttons | on |
| **CTA Button Count** | Number of CTA buttons (1–10) | `1` |
| **CTA Button Parameters** | Dynamic URL variables — one per button | `redeem?code={{coupon_code}}` |

<Tip>The **Add CTA Button** toggle controls a separate parameter list from the body parameters. Each CTA button parameter fills a dynamic placeholder in the button's URL, defined in the Kwik Engage template.</Tip>

## Example use case

**Points expiring — redeem now button**

1. In Kwik Engage, approve a template called `points_expiring_soon` with two body variables and one CTA button (URL = `https://shop.example.com/account?ref={dynamic}`). Note the endpoint URL.
2. In Yuko Workflows, build: **Trigger: Points Expiring Soon** → **WhatsApp (Kwik Engage)**.
3. Configure: Endpoint, Template Name = `points_expiring_soon`, Language = `en_US`, Parameter Count = `2`, Parameters = `{{first_name}}`, `{{points_balance}}`.
4. Toggle **Add CTA Button**, set CTA Button Count = `1`, Button Param 1 = `redeem-{{customer_id}}`.
5. Activate.

## Limitations

- **Approved templates only.** Kwik Engage enforces Meta template approval.
- **Template name must have no spaces.** Use underscores.
- **Up to 10 CTA buttons.** That's the Kwik Engage-side limit.
- **No template authoring inside Yuko.** Edit templates in the Kwik Engage dashboard.
- **No per-message delivery status surfaced in Yuko.** Check the Kwik Engage dashboard for delivered / read events.

## FAQs

<AccordionGroup>
  <Accordion title="Do I need to enable CTA buttons?">
    Only if your approved template has dynamic URL buttons. Leave the toggle off for plain text templates.
  </Accordion>
  <Accordion title="What goes into a CTA Button Parameter?">
    The dynamic part of the button's URL. If your template's button URL is `https://shop.example.com/{ref}`, the button param fills the `{ref}` placeholder.
  </Accordion>
  <Accordion title="What language codes does Kwik Engage support?">
    Standard WhatsApp Business API language codes — `en_US`, `hi_IN`, `en_GB`, etc. Use whatever matches the language of your approved template.
  </Accordion>
  <Accordion title="How do I rotate the API key?">
    Generate a new key in Kwik Engage, then paste it into the Yuko Kwik Engage integration tile and click **Connect** again.
  </Accordion>
</AccordionGroup>
