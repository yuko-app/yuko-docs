## What integrations do

Integrations let Yuko exchange data with the rest of your stack. Loyalty data lands in your email tool, loyalty events send WhatsApp templates and start Shopify Flow workflows, reviews from your reviews app earn points, returns can be refunded as points, store staff redeem points at the till, and your developers can build on the REST API and webhooks.

## The Integrations page

The Integrations page has a **Categories** sidebar on the left and a card grid on the right. Each card shows how the app connects (**OAuth** or **API Key**) and a **Connected** badge once it's set up. The button on each card says **Connect**, **Manage** (connected), **View setup** (a setup guide) or **Learn more** (a recommended app).

- With **All** selected, you see your **Connected** integrations first, then every other integration grouped by category.
- With a category selected, you see **Connected**, **Available** and **Recommended** apps in that category.
- The selected category stays in the page address, so going back from an integration reopens the same category.

### Categories

| Category | What lives here |
|---|---|
| **All** | Every integration, grouped by category |
| **Email & SMS** | Klaviyo, Mailchimp, Omnisend, Retainful |
| **WhatsApp** | 14 WhatsApp Business API providers |
| **Reviews** | Judge.me, plus Shopify Flow setup guides for Loox, Yotpo, Okendo, Stamped and Junip (Shopify stores only) |
| **Shopify Flow** | Shopify Flow |
| **Shopify POS** | Shopify POS (Shopify stores only) |
| **Returns & Exchanges** | Return Prime (Shopify stores only) |
| **Developer** | REST API, Webhook |
| **Recommended** | Shopify themes and apps Yuko recommends. These open the partner's page in a new tab. (Shopify stores only) |

A category only appears when it has at least one integration, and each category shows how many integrations it holds. Some integrations are available on select plans; cards you can't use yet show an upgrade badge and their button is disabled.

## How connectors work

- Each connector authenticates with the partner by **OAuth** or **API Key**. A few, such as Shopify Flow and Shopify POS, just need a toggle. Some need a second credential, such as WappCloud's **Access Token**.
- Once connected, the integration moves to the **Connected** section and its page shows the connection status and date. For API key connections, an **API credentials** section shows part of the key in use, so you can match it against the one your provider issued.
- Many integrations let you choose what to send, for example which events go to Klaviyo, Mailchimp, Omnisend, Retainful or Shopify Flow, or which Judge.me webhooks to register. Events for a module you've turned off are hidden from these lists.
- To disconnect, open the integration, switch off its toggle and confirm in the dialog.

## Choosing your stack

- **Email:** Klaviyo, Mailchimp, Omnisend or Retainful.
- **WhatsApp:** pick whichever of the 14 providers you already use. See the [WhatsApp overview](/integrations/whatsapp) for a comparison.
- **In-store:** Shopify POS for redeeming points at the till.
- **Returns:** Return Prime to refund returns as points.
- **Reviews:** Judge.me, or Loox, Yotpo, Okendo, Stamped, Junip or any other app that can run the Shopify Flow **Add Points for Review** action.
- **Custom builds:** REST API and Webhooks for anything the connectors don't cover.

## Best practices

<Tip>**Connect only what you'll use.** Each active integration is a moving part to maintain and a credential to rotate.</Tip>
<Tip>**Use webhooks for real-time data.** Polling the REST API is slower and rate-limited.</Tip>
<Tip>**Test in a development store** before connecting production partners.</Tip>
<Tip>**Use the category sidebar** to find integrations quickly.</Tip>
