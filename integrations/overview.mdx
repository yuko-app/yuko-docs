## What integrations do

Integrations let Yuko exchange data with the rest of your stack. Customers land in your email tool, loyalty events fire WhatsApp templates, review submissions become loyalty points, and your developers can build custom flows on top of the REST API + webhooks.

## The integrations page

The Integrations page uses a **category sidebar** on the left and a card grid on the right. Cards are grouped into three sections:

1. **Connected** — integrations you've already wired up. Click a card to open its detail page.
2. **Available** — integrations you can connect. Click a card to start the connection flow.
3. **Recommended** — curated third-party apps Yuko recommends (Shopify themes, checkout accelerators, etc.). These open the partner's page in a new tab.

## How connectors work

- Each connector authenticates with the partner (OAuth or API key).
- Once connected, Yuko exchanges the relevant data — customers, points, tier changes, events.
- The integration appears in the **Connected** section on the Integrations page with connection status, last-sync info and any error history.
- Some integrations expose per-event toggles (e.g., choose which loyalty events sync to Klaviyo, or which Judge.me webhooks to subscribe to).

## Choosing your stack

- **Email:** Klaviyo (deepest loyalty sync), Omnisend, or Retainful.
- **WhatsApp:** 11 providers to pick from — use whichever BSP you already have a contract with. See the [WhatsApp overview](/integrations/whatsapp) for a per-provider comparison.
- **Reviews platform:** Judge.me if you use Judge.me instead of Yuko's own reviews module.
- **Checkout widgets:** Checkout Boost for a one-toggle provision of a scoped REST key.
- **Custom flows:** REST API + Webhooks + Custom Apps for anything the connectors don't cover.

## Best practices

<Tip>**Connect only what you'll use.** Each active integration is a moving part to maintain and a credential to rotate.</Tip>
<Tip>**Use Webhooks for real-time** — polling the REST API is slower and rate-limited.</Tip>
<Tip>**Test in a development store** before wiring production partners.</Tip>
<Tip>**Use the category sidebar** to find integrations quickly — with 20+ options the flat list gets long.</Tip>
