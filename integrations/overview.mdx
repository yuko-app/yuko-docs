## What integrations do

Integrations let Yuko exchange data with the rest of your stack. Loyalty data lands in your email tool, loyalty events send WhatsApp templates and start Shopify Flow workflows, reviews from your reviews app earn points, store staff redeem points at the till, and your developers can build on the REST API and webhooks.

## The Integrations page

The Integrations page has a **category sidebar** on the left and a card grid on the right. Each card shows how the app connects (**OAuth** or **API Key**) and a **Connected** badge once it's set up. Cards are grouped into:

1. **Connected**: integrations you've already set up. Click a card to open its settings.
2. **Available**: integrations you can connect. Click a card to start connecting.
3. **Recommended**: third-party apps Yuko recommends. These open the partner's page in a new tab.

### Categories

| Category | What lives here |
|---|---|
| **All** | Every integration, including Judge.me |
| **Email & SMS** | Klaviyo, Omnisend, Retainful |
| **WhatsApp** | 13 WhatsApp Business API providers |
| **Shopify Flow** | Shopify Flow and Checkout Boost |
| **Shopify POS** | Shopify POS (Shopify stores only) |
| **Developer** | REST API, Webhooks |
| **Recommended** | Recommended third-party apps (Shopify stores only) |

A category only appears when it has at least one integration. Some integrations are available on select plans; cards you can't use yet show an upgrade badge.

## How connectors work

- Each connector authenticates with the partner by **OAuth** or **API Key**. A few, such as Shopify Flow, Shopify POS and Checkout Boost, just need a toggle.
- Once connected, the integration moves to the **Connected** section and its page shows the connection status.
- Many integrations let you choose what to send, for example which events go to Klaviyo, Omnisend, Retainful or Shopify Flow, or which Judge.me webhooks to register.
- To disconnect, open the integration and use **Disconnect** (or switch off its toggle).

## Choosing your stack

- **Email:** Klaviyo, Omnisend or Retainful.
- **WhatsApp:** pick whichever of the 13 providers you already use. See the [WhatsApp overview](/integrations/whatsapp) for a comparison.
- **In-store:** Shopify POS for redeeming points at the till.
- **Reviews:** Judge.me, or any app that can run the Shopify Flow **Add Points for Review** action.
- **Custom builds:** REST API and Webhooks for anything the connectors don't cover.

## Best practices

<Tip>**Connect only what you'll use.** Each active integration is a moving part to maintain and a credential to rotate.</Tip>
<Tip>**Use webhooks for real-time data.** Polling the REST API is slower and rate-limited.</Tip>
<Tip>**Test in a development store** before connecting production partners.</Tip>
<Tip>**Use the category sidebar** to find integrations quickly.</Tip>
