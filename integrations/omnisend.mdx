## Introduction

The Omnisend connector mirrors what the Klaviyo one does — customer profiles, custom properties and loyalty events flow into Omnisend so you can segment and trigger flows on them.

## When to use

- Omnisend is your primary email/SMS tool.
- You want loyalty events available inside Omnisend's automation flows.
- You want VIP segments in Omnisend for targeted campaigns.

## What syncs

- **Contact properties** — each event updates the contact with Yuko's `yuko_*` loyalty properties (points balance, VIP tier, referral link and so on) as Omnisend custom properties.
- **Events** — the Yuko events you select on the integration page are sent to Omnisend, so you can trigger automations on them.

## Points expiring soon properties

Alongside the balance, tier and referral properties, Yuko sends four properties that help you build "use your points before they expire" campaigns:

| Property | Type | Description |
|---|---|---|
| `yuko_points_expiring_in_30_days` | Integer | Points that expire within the next 30 days (includes the 7-day amount). `0` if none. |
| `yuko_points_expiring_in_7_days` | Integer | Points that expire within the next 7 days. `0` if none. |
| `yuko_points_expiring_in_30_days_as_cash_balance` | Number | The 30-day expiring points expressed in store currency. |
| `yuko_points_expiring_in_7_days_as_cash_balance` | Number | The 7-day expiring points expressed in store currency. |

The property names are the same as in the [Klaviyo](/integrations/klaviyo#loyalty-profile-properties) integration, which lists the full property set.

## Prerequisites

<Check>You have an Omnisend account.</Check>
<Check>You have an Omnisend API key.</Check>

## Setup

<Steps>
  <Step title="Open Omnisend integration">
    Go to **Apps → Yuko Loyalty → Integrations → Omnisend**.
  </Step>
  <Step title="Connect with the API key">
    Paste your Omnisend API key into **API Key** and click **Connect Integration**.
  </Step>
  <Step title="Pick events to sync">
    Select the events to send to Omnisend and click **Save Events**.
  </Step>
  <Step title="Test (optional)">
    Click **Send Test Events** to send sample events and check them in Omnisend.
  </Step>
</Steps>

## Common use cases

- VIP-tier segments in Omnisend.
- Loyalty-driven SMS / WhatsApp messages via Omnisend's multi-channel features.
- Re-engagement flows triggered by *Tier downgrade* events.

## Best practices

<Tip>**Pick one tool to send loyalty emails.** Either Yuko or Omnisend, not both.</Tip>
<Tip>**Test with a real customer record** before activating Omnisend flows.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="Does Omnisend replace Yuko's emails?">
    Only if you want it to — disable the corresponding Yuko templates if you do.
  </Accordion>
</AccordionGroup>
