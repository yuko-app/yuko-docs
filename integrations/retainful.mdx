</Note>

## Introduction

The Retainful connector flows Yuko's customer and loyalty data into Retainful so you can use it in abandoned-cart and lifecycle email campaigns.

## When to use

- You're already on Retainful for email.
- You want loyalty data segmenting your Retainful sends.

## Prerequisites

<Check>You have a Retainful account and API key.</Check>

## Setup

<Steps>
  <Step title="Open Retainful integration">
    Go to **Apps → Yuko Loyalty → Integrations → Retainful**.
  </Step>
  <Step title="Connect with API key">
    Paste your Retainful API key.
  </Step>
  <Step title="Save">
    Customer attributes flow into Retainful from there.
  </Step>
</Steps>

## Best practices

<Tip>**Use Retainful for cart-abandonment**, Yuko Workflows for loyalty-specific automations.</Tip>
