## Introduction

Workflows are automations you build on a visual canvas. Each workflow starts with one **trigger** (an event such as *Earn Points*, *VIP Tier Upgrade* or *Order Delivered*), then runs the steps you add: wait, branch with **If / Else**, send an email or WhatsApp message, create a coupon, or credit or debit points.

Use workflows when the [built-in emails](/emails/overview) aren't enough, for example to send a WhatsApp message when a customer reaches a new tier, wait three days before a follow-up, or treat VIP customers differently from everyone else.

## How a workflow fits together

```
Trigger  ──→  Time Delay  ──→  If / Else ──Yes──→  Send Email  ──→  Exit
                                   │
                                   └──No───→  WhatsApp  ──→  Exit
```

- **Trigger:** the event that starts the workflow, plus optional trigger and profile filters and re-entry rules. See [Triggers & Conditions](/workflows/triggers-and-conditions).
- **Actions:** **Send Email**, **Coupon**, **Points Credit**, **Points Debit**, **WhatsApp**, **Engati** and **kwikEngage**. See [Action Nodes](/workflows/action-nodes), the [WhatsApp node](/workflows/whatsapp-node) and [Partner Nodes](/workflows/partner-nodes).
- **Timing:** **Time Delay**. See [Time Delay & Exit](/workflows/wait-and-exit).
- **Logic:** **If / Else** splits customers into a **Yes** and a **No** path.
- **Exit:** every path ends in an Exit node that Yuko adds for you.

Each customer who enters a workflow is a **subscriber**. You can follow every subscriber's path in [Analytics](/workflows/analytics).

## The Workflows list

- **Create Workflow** → **Create from Scratch** opens a new, blank workflow.
- Tabs: **All**, **Live** and **Draft**, plus an **Event Type** filter and search.
- Columns: **Title**, **Trigger Type**, **Subscribers** and **Status** (**Live** or **Draft**).
- Select several workflows to set them Live, set them to Draft, or delete them in bulk.

New workflows start as **Draft**. Changes on the canvas save automatically. When you're ready, click **Turn on workflow** to make it **Live**. Running workflows Live is available on select plans.

<Info>The workflow editor needs a desktop-sized screen. On a phone, Yuko shows *"Workflow editor requires desktop view"*.</Info>

## Workflows and built-in emails

The emails under **Loyalty → Emails**, **Referral → Emails** and **Membership → Emails** run on the same engine, but you manage them from those tabs, not from the Workflows list. If you build a workflow on the same trigger as a built-in email, turn the built-in email off so customers don't get two messages.

## Best practices

<Tip>**Start small.** A trigger, one action and an exit is a complete workflow. Add branches once the basics work.</Tip>
<Tip>**Set re-entry deliberately.** Decide whether a customer should go through the workflow once, every time, or at most once per period.</Tip>
<Tip>**Check Analytics after launch.** Failed steps show the reason, so you can fix setup issues early.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="Are there ready-made workflow templates?">
    Not today. New workflows start from scratch with **Create from Scratch**.
  </Accordion>
  <Accordion title="What happens to customers already in a workflow if I set it to Draft?">
    A Draft workflow stops accepting new subscribers. Customers who are already in it, for example waiting on a Time Delay, carry on through their remaining steps. Check [Analytics](/workflows/analytics) for subscribers still marked **In Progress**.
  </Accordion>
  <Accordion title="Can a workflow call my own server?">
    Not from the workflow builder. For outbound data, see [Integrations](/integrations/overview).
  </Accordion>
</AccordionGroup>
