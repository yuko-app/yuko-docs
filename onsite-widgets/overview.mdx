## What are onsite widgets

Onsite widgets are the customer-facing parts of your loyalty program. They show points balances, what customers can earn, rewards to redeem and VIP status at each step of the shopping journey, with no theme code to write.

Each widget has a toggle to switch it on and a **Customize** button to edit its text, colours and settings. **Customize Branding** at the top of the page sets colours for all widgets at once. See [Branding & Locale](/onsite-widgets/branding-and-locale).

Widgets render through three kinds of Shopify extension:

- **Theme app extension**: the **Yuko App** app embed (Floating Rewards, Loyalty Nudges and automatic cart placement) and the Yuko theme blocks you add in the theme editor (product, cart and landing page blocks).
- **Checkout UI extension**: blocks inside Shopify Checkout.
- **Customer account UI extension**: blocks on the Order status, Orders and Profile pages, plus a full loyalty page, in Shopify's new customer accounts.

## The Widgets list

Widgets are grouped as they appear in the admin.

### Landing & Promotional

| Widget | Where it appears | How it renders |
|---|---|---|
| [Floating Rewards](/onsite-widgets/floating-launcher) (Recommended) | A floating button and panel on every page | Yuko App embed |
| [Rewards Landing Page](/onsite-widgets/rewards-landing-page) (Recommended) | A loyalty page at `/pages/loyalty-info-page` | Seven Yuko theme blocks |
| [Loyalty Nudges](/onsite-widgets/loyalty-nudges) | A strip pinned to the top or bottom of every page | Yuko App embed |

### Shopping Cart

| Widget | Where it appears | How it renders |
|---|---|---|
| [Product page](/onsite-widgets/product-page-earn) | Product detail page | Theme block **Yuko:Product Earn Message** |
| [Cart earn message](/onsite-widgets/cart-earn) | Cart page or drawer | Automatic placement through the Yuko App embed, or theme block **Yuko: Cart Earn Message** |
| [Cart redeem message](/onsite-widgets/cart-redeem) | Cart page or drawer | Automatic placement through the Yuko App embed, or theme block **Yuko: Cart Redeem Message** |

### Checkout Process

| Widget | Where it appears | How it renders |
|---|---|---|
| [Checkout: Earn points](/onsite-widgets/checkout-earn) | Shopify Checkout | Checkout UI extension block **Yuko Potential points earn** |
| [Checkout: Redeem points](/onsite-widgets/checkout-redeem) | Shopify Checkout | Checkout UI extension block **Yuko Redeem rewards** |

<Info>
Checkout widgets are **available only on the Shopify Plus plan**, because Shopify allows checkout UI extension blocks only on Plus stores. They're also available on select Yuko plans.
</Info>

## Languages and logged-out customers

- **Languages:** every widget editor has an **Editing language** picker when your store publishes more than one language. Each language keeps its own copy of the widget text. See [Branding & Locale](/onsite-widgets/branding-and-locale).
- **Custom login trigger:** when a logged-out customer signs in from Floating Rewards, Loyalty Nudges or Cart redeem, Yuko sends them to the Shopify account login by default. If your store uses its own login, set a **Custom login trigger** (a CSS element to click, or a login link) in [Loyalty → Settings](/loyalty/program-settings).

## Decision guidance

- **Start with the recommended pair:** Floating Rewards keeps the program one tap away on every page, and the Rewards Landing Page gives your emails, ads and footer a destination.
- **Add cart widgets** so customers see what they'll earn and can redeem before checkout.
- **Add checkout widgets** if you're on Shopify Plus.
- **Add the customer account widgets** so balances and rewards show up where customers check their orders.
- **Add Loyalty Nudges** when you run booster campaigns and want them visible on every page.

## Best practices

<Tip>**Less is more.** Pick the surfaces that matter for your store rather than switching everything on.</Tip>
<Tip>**Keep widget copy short.** Link to the Rewards Landing Page for the full explanation.</Tip>
<Tip>**Always test on mobile.** Most loyalty interactions happen on phones.</Tip>
