## Introduction

The **Cart earn message** shows the points a customer will earn for the items currently in their cart. It updates as the cart changes.

## What problem this solves

The cart is where customers decide whether to check out. Showing the points they're about to earn gives them one more reason to complete the order, and to add one more item.

## Where it appears

- Cart page and cart drawer. It is placed automatically through the **Yuko App** embed, or wherever you add the **Yuko: Cart Earn Message** block.

## When to use

- You want a simple earn reminder at the cart.
- You run spend-based earning, so the points grow as the cart grows.

## Overview

- One message field with placeholders, plus a default or custom icon.
- Automatic placement above your theme's cart footer, or a **Custom placement** selector.
- Styles tab with four colours, padding, height and **Custom CSS**.
- Updates when items are added, removed or changed.

## Setup guide

### 1. Configure the widget in Yuko

<Steps>
  <Step title="Open the widget settings">
    Go to **Loyalty → Widgets**, find **Cart earn message** under **Shopping Cart**, and click **Customize**.
  </Step>
  <Step title="Edit the message">
    **Cart earn message**. Default: `You'll earn [points_value] [points_label] on this purchase!`
  </Step>
  <Step title="Choose an icon">
    Under **Customize cart earn message icon**, keep **Default** or choose **Custom** to upload your own icon (JPG, PNG, GIF or WEBP, under 1 MB).
  </Step>
  <Step title="Set a custom placement (optional)">
    Leave **Custom placement** empty to let Yuko place the message above your theme's cart footer. To put it somewhere else, enter a CSS selector, for example `.cart__footer`. Yuko inserts the message just before each matching element.
  </Step>
  <Step title="Adjust styles (optional)">
    On the **Styles** tab, set:
    - **Color Configuration:** Primary color, Secondary color, Text color and Body description color.
    - **Widget Style:** Padding (px, default 10) and Height (px, leave empty for automatic).
    - **Custom CSS:** add your own CSS rules for this widget.
  </Step>
  <Step title="Save and enable">
    Click **Save**. Back on **Loyalty → Widgets**, switch the widget's toggle on.
  </Step>
</Steps>

### 2. Make sure it can render on your theme

Automatic placement needs the **Yuko App** embed. If it's off, the widget editor shows an **Enable Theme Extension** button that opens the theme editor so you can switch it on. See [Theme App Embed](/installation-and-setup/theme-app-embed).

To control the exact position yourself, add the block instead:

import SetupThemeBlock from '/snippets/setup-theme-app-block.mdx';

<SetupThemeBlock />

Pick the **Cart** template and add **Yuko: Cart Earn Message**. The block has no theme editor settings; all text and styling come from Yuko.

### 3. Verify

Add a product to the cart on your live store. Check that the message shows on the cart page and in the cart drawer, and that it updates when you change quantities.

## Available placeholders

| Placeholder | Replaced with |
|---|---|
| `[points_value]` | Total points earned with the purchase. |
| `[points_label]` | Your loyalty points label. |
| `[points_cash_value]` | Cash value of the points earned. |

## How it works

1. When the cart loads or changes, Yuko recalculates the points for the cart contents.
2. The message renders inside the block (if you added one) and in the automatically placed spot from the **Yuko App** embed.
3. Automatic placement uses your **Custom placement** selector if set; otherwise it uses common cart-footer positions in Shopify themes.

### Limitations

- The message is hidden when the cart earns 0 points (for example, an empty cart or excluded products).
- Automatic placement depends on your theme's cart markup. If the message doesn't appear, or appears in the wrong spot, use **Custom placement** or add the block.

## Best practices

<Tip>**Pair with Cart Redeem.** Customers should see what they'll earn and what they can spend.</Tip>
<Tip>**Test your Custom placement selector** on both the cart page and the cart drawer, since themes often use different markup for each.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="The message doesn't appear in my cart drawer">
    Check that the **Yuko App** embed is on. If it is, your theme's drawer may use markup Yuko doesn't recognise; enter a selector for an element inside your drawer in **Custom placement**.
  </Accordion>
  <Accordion title="The message appears twice">
    The block and automatic placement both render the message. If you added the **Yuko: Cart Earn Message** block and the embed also places it, remove the block and use **Custom placement** to position the automatic message instead.
  </Accordion>
</AccordionGroup>
