</Note>

## Introduction

**Branding Settings** sets the colours for your loyalty widgets in one place. Choose a ready-made palette or your own colours, then apply them to every widget at once.

Widget **language** is set per widget: each widget editor has an **Editing language** picker, so you can write its text in each language your store publishes.

## What problem this solves

Restyling a dozen widgets one by one is slow and easy to get inconsistent. Branding gives every widget the same colours in one save, and you can still fine-tune individual widgets afterwards.

## Where it applies

Branding colours can be applied to all loyalty widgets: Product page, Cart earn, Cart redeem, Checkout earn and redeem, Order status, Order list, Customer profile, the Customer account page, the Rewards Landing Page, Floating Rewards and Loyalty Nudges.

## When to use

- You're setting up widgets for the first time and want them all to match your store.
- You've rebranded and want to update every widget in one go.

## Overview

- **8 colour palettes** to start from.
- **5 colours** you can adjust: Primary, Secondary, Primary text, Secondary text and Icon.
- **Apply changes to all widgets?** copies the colours into every widget's own style settings.
- **Editing language** in each widget editor, for text in each of your store's published languages.

## Before you start

<Check>Yuko is installed and your loyalty program is set up.</Check>
<Check>For more than one language, the languages are published in your Shopify store (**Settings → Languages**).</Check>

## Setup guide

### Set your brand colours

<Steps>
  <Step title="Open Branding Settings">
    Go to **Apps → Yuko Loyalty → Loyalty → Widgets** and click **Customize Branding**.
  </Step>
  <Step title="Choose your colour palette">
    Pick one of the eight palettes: **Eclipse Black** (default), **Coral Pink**, **Herbal Green**, **Golden Ochre**, **Crimson Red**, **Expresso Brown**, **Pacific Blue** or **Modern Gray**. Choosing a palette fills in the colours below.
  </Step>
  <Step title="Customize colors">
    Adjust any of the five colours. Before you pick a palette, they start at these values:

    | Colour | Starting value |
    |---|---|
    | **Primary color** | `#000000` |
    | **Secondary color** | `#ffffff` |
    | **Primary text color** | `#000000` |
    | **Secondary text color** | `#666666` |
    | **Icon color** | `#000000` |
  </Step>
  <Step title="Apply to all widgets (optional)">
    Tick **Apply changes to all widgets?** to copy these colours into every loyalty widget. This overwrites any colours you've set on individual widgets.
  </Step>
  <Step title="Save">
    Click **Save**.
  </Step>
</Steps>

### Edit widget text in another language

<Steps>
  <Step title="Open a widget">
    Go to **Loyalty → Widgets** and click **Customize** on the widget.
  </Step>
  <Step title="Pick the language">
    At the top of the editor, choose a language from **Editing language**. Your default language is marked **(default)**. The picker appears only when your store has more than one language.
  </Step>
  <Step title="Write and save">
    Edit the text and click **Save**. Each language keeps its own copy of the widget's text. Repeat for each language.
  </Step>
</Steps>

Labels in your loyalty content, such as campaign names, reward names, VIP tier names and system labels, are translated separately in [Translations](/account/translations).

## How it works

- **Branding** stores your palette and colours. When **Apply changes to all widgets?** is ticked on save, Yuko writes those colours into each widget's style settings. After that, each widget keeps its own colours, so you can still change one widget without affecting the rest.
- **Language** is chosen on the storefront from the language the customer is browsing in. Yuko shows the widget text you saved for that language.

### Limitations

- Branding sets colours only. There are no logo, font or typography settings. Each widget has its own style options (such as **Custom CSS** and shapes) in its editor.
- Branding doesn't change your [loyalty emails](/emails/overview). Email branding is set separately.

## Best practices

<Tip>**Set branding first.** Pick your palette before you customise individual widgets, then tick **Apply changes to all widgets?** once.</Tip>
<Tip>**Re-apply after a rebrand.** Ticking **Apply changes to all widgets?** again brings every widget back in line.</Tip>
<Tip>**Write every language.** If you sell in several languages, open each widget in each language so customers never see untranslated text.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="Can I give one widget different colours?">
    Yes. Branding is a starting point. After applying it, open any widget and change its colours on its own Styles or Customization settings. Ticking **Apply changes to all widgets?** again later overwrites those changes.
  </Accordion>
  <Accordion title="I changed the branding colours, but my widgets didn't change">
    Colours reach existing widgets only when **Apply changes to all widgets?** is ticked when you save. Tick it and save again.
  </Accordion>
  <Accordion title="Can I upload a logo or change fonts here?">
    No. Branding covers colours only. For images, use the widget's own settings, such as **Banner images** in [Floating Rewards](/onsite-widgets/floating-launcher) or the image settings on the [Rewards Landing Page](/onsite-widgets/rewards-landing-page) blocks.
  </Accordion>
  <Accordion title="Why don't I see the Editing language picker?">
    It appears only when your store publishes more than one language. Add and publish languages in Shopify under **Settings → Languages**.
  </Accordion>
  <Accordion title="Where do I translate campaign and reward names?">
    In [Translations](/account/translations), which covers system labels and dynamic content such as campaigns, rewards and VIP tiers.
  </Accordion>
</AccordionGroup>
