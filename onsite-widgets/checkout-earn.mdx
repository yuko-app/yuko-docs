<Note>
**Where to find this:** Shopify admin → Apps → Yuko Loyalty → Loyalty → Widgets → Checkout: Earn points
</Note>

## Introduction

The **Checkout: Earn points** widget shows the points a customer will earn on the order, inside Shopify Checkout. It's the **Yuko Potential points earn** checkout UI extension block.

## What problem this solves

Checkout is the last step before the order is placed. A reminder of the points the customer is about to earn reinforces the value of completing the purchase.

## Where it appears

- Shopify Checkout, in the order summary by default. You can move the block in the checkout editor.

## When to use

- Your store is on Shopify Plus.
- You want the earn message to follow the customer all the way to payment.

## Overview

- A checkout UI extension block on the `purchase.checkout.block.render` target, named **Yuko Potential points earn**.
- Two text fields: a title and a message.
- No Styles tab; the block uses Shopify Checkout's own styling.
- Recalculates as the checkout total changes.

<Info>
On the Widgets list, checkout widgets show the note **Available only on Shopify Plus plan** when your store isn't on Shopify Plus. This widget is also available on select Yuko plans.
</Info>

## Setup guide

### 1. Configure the widget in Yuko

<Steps>
  <Step title="Open the widget settings">
    Go to **Loyalty → Widgets**, find **Checkout: Earn points** under **Checkout Process**, and click **Customize**.
  </Step>
  <Step title="Edit the text">
    - **Checkout earn title**: default `Earn [points_label]`
    - **Checkout earn message**: default `Earn up to [points_value] [points_label] for this purchase!`
  </Step>
  <Step title="Save and enable">
    Click **Save**. Back on **Loyalty → Widgets**, switch the widget's toggle on.
  </Step>
</Steps>

### 2. Add the block in the checkout editor

import SetupCheckout from '/snippets/setup-checkout-extension.mdx';

<SetupCheckout />

Choose the **Yuko Potential points earn** block. By default it sits in the order summary; drag it wherever suits your checkout. See [Checkout UI Extension](/installation-and-setup/checkout-ui-extension) for more detail.

### 3. Verify

Start a checkout on your live store and check that the block shows the expected points.

## Available placeholders

| Placeholder | Replaced with |
|---|---|
| `[points_value]` | The points the order will earn. |
| `[points_label]` | Your loyalty points label. |
| `[points_cash_value]` | Cash value of the points earned. |

## How it works

1. Shopify loads the **Yuko Potential points earn** block in checkout.
2. Yuko calculates the points for the current checkout from your active earn rules.
3. If the order earns points, the block shows your title and message. If it earns nothing, the block stays hidden.
4. When the checkout total changes, the points are recalculated.

### Limitations

- Shopify only allows checkout UI extension blocks on Shopify Plus stores.
- The block's look follows Shopify Checkout's styling; you can't add custom CSS.

## Best practices

<Tip>**Keep the message short.** Checkout is a busy screen; one line is enough.</Tip>
<Tip>**Pair with [Checkout: Redeem points](/onsite-widgets/checkout-redeem)** so customers can also spend points before paying.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="My checkout doesn't show the widget">
    Check that your store is on Shopify Plus, that the **Yuko Potential points earn** block is added and saved in the checkout editor, that the widget toggle is on in **Loyalty → Widgets**, and that the order actually earns points.
  </Accordion>
  <Accordion title="What about the order status page?">
    Use the [Order Status: Earn Points Message](/onsite-widgets/order-status-earn) widget. It confirms the points earned after the order is placed.
  </Accordion>
</AccordionGroup>
