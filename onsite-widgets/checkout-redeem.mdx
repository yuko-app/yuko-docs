## Introduction

The **Checkout: Redeem points** widget lets customers apply rewards they already have, or redeem points for a new reward, without leaving Shopify Checkout. It's the **Yuko Redeem rewards** checkout UI extension block.

## What problem this solves

Customers who decide to use their points at checkout shouldn't have to go back to the cart. Redeeming inside checkout keeps them moving towards payment.

## Where it appears

- Shopify Checkout, at the top of the order summary by default. You can move the block in the checkout editor.

## When to use

- Your store is on Shopify Plus.
- You want customers to redeem at the most decisive screen.

## Overview

- A checkout UI extension block on the `purchase.checkout.block.render` target, named **Yuko Redeem rewards**.
- An **existing rewards** row: pick a code the customer already has and apply it.
- A **redeem** row: pick a reward and redeem points for it. Rewards set to **Incremented points** show a points stepper.
- A login prompt for guests.
- A **Visibility** option to hide the widget for customers with specific tags.
- No Styles tab; the block uses Shopify Checkout's own styling.

<Info>
On the Widgets list, checkout widgets show the note **Available only on Shopify Plus plan** when your store isn't on Shopify Plus. This widget is also available on select Yuko plans.
</Info>

## Setup guide

### 1. Configure the widget in Yuko

<Steps>
  <Step title="Open the widget settings">
    Go to **Loyalty → Widgets**, find **Checkout: Redeem points** under **Checkout Process**, and click **Customize**.
  </Step>
  <Step title="Edit the text">
    | Field | Default |
    |---|---|
    | **Header title** | `Redeem your [points_label] for rewards` |
    | **Point balance text** | `You have [point_balance] [points_label]. Redeem them for rewards.` |
    | **Reward selection label** | `Select a reward` |
    | **Points to redeem label** | `[points_label] to redeem` |
    | **Summary text** | `[points_to_redeem] [points_label] for [discount_value] off` |
    | **Redeem button text** | `Redeem` |
    | **Apply button text** | `Apply` |
    | **Existing rewards label** | `Your rewards` |
    | **Login link text** | `Log in` |
    | **Login prompt text** | `to claim loyalty rewards.` |
  </Step>
  <Step title="Set visibility (optional)">
    Under **Visibility**, turn on **Hide widget for customers with specific tags**, then search for and select the **Customer tags** to hide it from. Customers with any of these tags won't see the widget.
  </Step>
  <Step title="Save and enable">
    Click **Save**. Back on **Loyalty → Widgets**, switch the widget's toggle on.
  </Step>
</Steps>

### 2. Add the block in the checkout editor

<SetupCheckout />

Choose the **Yuko Redeem rewards** block. By default it sits at the top of the order summary, close to the discount code field. See [Checkout UI Extension](/installation-and-setup/checkout-ui-extension) for more detail.

### 3. Verify

<Steps>
  <Step title="Test as a logged-in customer">
    Log in as a customer with enough points, start a checkout, redeem a reward and check that the discount is applied.
  </Step>
  <Step title="Test as a guest">
    Start a checkout without logging in. You should see the login link and prompt.
  </Step>
</Steps>

## Available placeholders

| Placeholder | Replaced with |
|---|---|
| `[points_label]` | Your loyalty points label. |
| `[point_balance]` | Customer's available points balance. |
| `[points_cash_value]` | Cash value of the customer's points. |
| `[points_to_redeem]` | Points being redeemed. |
| `[discount_value]` | The discount amount the customer will get. |

## How it works

1. Shopify loads the **Yuko Redeem rewards** block in checkout.
2. **Logged-in customers** see the header and their balance, then:
   - an existing rewards row (when they have unused codes) to pick a code and click **Apply**;
   - a redeem row (when they can afford at least one reward) to pick a reward and click **Redeem**.
3. For rewards set to **Incremented points**, a points stepper appears under the redeem row. It starts at the most the customer can redeem, moves in steps of the reward's points, and respects the reward's minimum and maximum. The **Summary text** shows what they'll get.
4. Clicking **Redeem** creates the discount code and applies it to the checkout.
5. **Guests** see the **Login link text** and **Login prompt text**. The link sends them to your store's login page and back to checkout afterwards. They also see the rewards list, so they know what logging in unlocks.
6. The widget stays hidden if the customer has a hidden tag, or if there's nothing to show.

### Limitations

- Shopify only allows checkout UI extension blocks on Shopify Plus stores.
- The block's look follows Shopify Checkout's styling; you can't add custom CSS.
- Whether a loyalty discount combines with other discounts depends on the reward's combination settings in Shopify.

## Best practices

<Tip>**Place it near the discount field.** Customers look there when they want to save money.</Tip>
<Tip>**Hide it for wholesale or staff tags** with **Hide widget for customers with specific tags**, if those customers shouldn't redeem points.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="A logged-in customer doesn't see the widget">
    The widget hides when the customer has no unused rewards and can't afford any reward, or when they have one of the tags you chose under **Visibility**.
  </Accordion>
  <Accordion title="What is the points stepper?">
    It appears for rewards set to **Incremented points**. Customers choose how many points to redeem, in steps of the reward's points, and the **Summary text** shows the resulting discount.
  </Accordion>
</AccordionGroup>
