## How shortcodes work

Shortcodes are placeholders that Yuko replaces with the customer's real data when the email is sent. Wrap the key in double curly braces, for example `{{ first_name }}` or `{{ points_balance }}`. Spaces inside the braces are optional.

Each email only supports the shortcodes for its own event. The editor lists exactly the ones you can use, so copy them from there. The tables below show which emails support each shortcode.

<Info>Shortcodes are rendered with Liquid, so you can also use simple conditions. For example, `{% if current_tier_name == "Gold" %} ... {% endif %}` shows a block only to Gold members.</Info>

| Shortcode | Label | Available in |
|---|---|---|

| `{{ points_balance }}` | Points Balance | All loyalty emails; Referrer reward issued |
| `{{ total_earned_points }}` | Total Earned Points | All loyalty emails |
| `{{ total_redeemed_points }}` | Total Redeemed Points | All loyalty emails |
| `{{ points_to_next_reward }}` | Points to Next Reward | Points earned, Points redeemed, Point Expiry Reminder, Points expired; Friend reward unlocked |
| `{{ total_orders }}` | Total Orders | Points earned, Points redeemed, Tier unlocked, Point Expiry Reminder, Points expired, Birthday and Anniversary emails |
| `{{ points_value_as_cash }}` | Points Value as Cash | Points earned, Birthday Reminder, Anniversary Reminder |
| `{{ points_balance_as_cash }}` | Points Balance as Cash | Points earned, Points redeemed, Birthday and Anniversary emails; Referrer reward issued |

## Redemption

Added to **every** email.

| Shortcode | Label | What it does |
|---|---|---|
| `{{ redemption_link }}` | Redemption Link | A personal, signed link to your store's primary domain. It identifies the customer to Yuko's storefront widgets, so they can see their points and redeem without signing in first. |
| `{{ redemption_link_params }}` | Redemption Link Params | Only the query string of that link (starting with `?`), so you can add it to another store URL, such as a collection page. |

<Tip>Use `{{ redemption_link }}` as the CTA URL in points-earned or points-expiring emails so customers can turn points into a reward in one click.</Tip>

## Best practices

<Tip>**Copy shortcodes from the editor.** The **Available Template Variables** card only lists shortcodes that work in the email you're editing. A shortcode from another email will print nothing.</Tip>
<Tip>**Plan for empty values.** `{{ first_name }}` is empty when Shopify has no first name, and `{{ next_tier_name }}` is empty for top-tier customers. Write copy that still reads well, or wrap it in a Liquid `{% if %}` block.</Tip>
<Tip>**Send a test after editing.** Tests use sample data, so you can check the layout without waiting for a real event.</Tip>

## FAQs

<AccordionGroup>
  <Accordion title="Do the old square-bracket shortcodes like [first_name] still work?">
    No. Use double curly braces: `{{ first_name }}`.
  </Accordion>
  <Accordion title="Can I use these shortcodes in workflow emails?">
    Yes. A Send Email node in a [workflow](/workflows/action-nodes#send-email) gets the shortcodes for the workflow's trigger, plus the Redemption group.
  </Accordion>
  <Accordion title="Is there a store name or store URL shortcode?">
    Not in loyalty, referral or membership emails. Type your store name directly, and use the CTA URL for links.
  </Accordion>
</AccordionGroup>
