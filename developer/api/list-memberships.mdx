---
title: "Get customer membership"
api: "GET /public/customers/memberships"
description: "Returns a customer's loyalty membership summary, including points balance, current VIP tier and progress toward the next tier."
---

If VIP tiers are turned off for the store, the tier fields are `null`.

<Info>Requires the `read:customers` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="customer_id" type="string" required>
  The platform customer ID (for example, the Shopify customer ID). If you leave it out, this endpoint returns a `500` `internal_error` rather than a `422` validation error, so always send it.
</ParamField>

## Response

<ResponseField name="data" type="object">
  The customer's membership summary.

  <Expandable title="membership properties">
    <ResponseField name="status" type="string">
      The customer's loyalty membership status. Always `active`.
    </ResponseField>
    <ResponseField name="member_since" type="string<date-time>">
      When the customer was created in Yuko (ISO 8601).
    </ResponseField>
    <ResponseField name="points" type="object">
      The customer's current points summary.

      <Expandable title="points properties">
        <ResponseField name="balance" type="integer">
          The customer's current redeemable points balance. Always `0` for customers who are banned or excluded from the loyalty program by a customer tag.
        </ResponseField>
        <ResponseField name="earned" type="integer">
          Total points ever earned by the customer.
        </ResponseField>
        <ResponseField name="redeemed" type="integer">
          Total points redeemed by the customer.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="current_tier" type="object | null">
      The customer's current VIP tier. `null` if the customer has not reached any tier threshold or VIP tiers are turned off.

      <Expandable title="current_tier properties">
        <ResponseField name="id" type="string<uuid>">
          The tier's unique identifier.
        </ResponseField>
        <ResponseField name="name" type="string">
          The tier's name.
        </ResponseField>
        <ResponseField name="threshold_value" type="integer">
          The qualifying value needed to reach the tier.
        </ResponseField>
        <ResponseField name="multiplier" type="number">
          The tier's multiplier.
        </ResponseField>
        <ResponseField name="icon" type="object | null">
          The tier icon, or `null` if none is set. Contains `source` (`default` or `custom`), `slug` (built-in icons), `id` (custom uploads) and `url` (the image URL).
        </ResponseField>
        <ResponseField name="benefits" type="object[]">
          The benefits associated with this tier.

          <Expandable title="benefit properties">
            <ResponseField name="name" type="string">
              The benefit's name.
            </ResponseField>
            <ResponseField name="benefit_type" type="enum<string>">
              The kind of benefit. One of `fixed`, `percentage`, `free_product`, `free_shipping`, `bonus_points`, `store_credit`, `custom`.
            </ResponseField>
            <ResponseField name="benefit_value" type="object">
              The benefit's settings. Its shape depends on `benefit_type`.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="created_at" type="string<date-time>">
          When the tier was created (ISO 8601).
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="next_tier" type="object | null">
      The next VIP tier the customer can reach, with the same fields as `current_tier`. `null` if the customer is already at the highest tier, hasn't been evaluated for tiers yet, or VIP tiers are turned off.

      <Expandable title="next_tier properties">
        <ResponseField name="id" type="string<uuid>">
          The tier's unique identifier.
        </ResponseField>
        <ResponseField name="name" type="string">
          The tier's name.
        </ResponseField>
        <ResponseField name="threshold_value" type="integer">
          The qualifying value needed to reach the tier.
        </ResponseField>
        <ResponseField name="multiplier" type="number">
          The tier's multiplier.
        </ResponseField>
        <ResponseField name="icon" type="object | null">
          The tier icon, or `null` if none is set. Same shape as `current_tier.icon`.
        </ResponseField>
        <ResponseField name="benefits" type="object[]">
          The benefits associated with the next tier. Same shape as `current_tier.benefits`.

          <Expandable title="benefit properties">
            <ResponseField name="name" type="string">
              The benefit's name.
            </ResponseField>
            <ResponseField name="benefit_type" type="enum<string>">
              The kind of benefit. One of `fixed`, `percentage`, `free_product`, `free_shipping`, `bonus_points`, `store_credit`, `custom`.
            </ResponseField>
            <ResponseField name="benefit_value" type="object">
              The benefit's settings. Its shape depends on `benefit_type`.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="created_at" type="string<date-time>">
          When the tier was created (ISO 8601).
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="progress_to_next_tier" type="object | null">
      The customer's progress toward the next tier. `null` if there's no `next_tier` or VIP tiers are turned off.

      <Expandable title="progress_to_next_tier properties">
        <ResponseField name="current_value" type="integer">
          The customer's current qualifying value (points earned, amount spent or orders placed), rounded down to a whole number.
        </ResponseField>
        <ResponseField name="required_value" type="integer">
          The value required to reach the next tier.
        </ResponseField>
        <ResponseField name="remaining_value" type="integer">
          The remaining value needed to reach the next tier.
        </ResponseField>
        <ResponseField name="progress_percentage" type="number">
          The percentage of the way to the next tier, rounded to 2 decimal places.
        </ResponseField>
        <ResponseField name="threshold_type" type="enum<string> | null">
          The metric used to determine tier progression. One of `total_earned_points`, `total_amount_spents`, `total_orders`. Can be `null` even when VIP tiers are set up, so don't rely on it; the metric is set in your VIP tier settings.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:customers`. |
| `404` | `not_found` | No customer matches `customer_id`. Message: "Customer not found". |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |
| `500` | `internal_error` | `customer_id` was left out. Message: "An unexpected error occurred. Please try again later." |
