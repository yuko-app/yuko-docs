---
title: "List membership plans"
api: "GET /public/memberships"
description: "Retrieves a paginated list of your store's active paid membership plans."
---

Only plans with the **Active** status are returned. They're sorted in the order they appear in Yuko. Learn more about plans in [Membership plans](/memberships/plans).

<Info>Requires the `read:customers` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="per_page" type="integer" default={20}>
  The number of results per page. Values above `100` are treated as `100`.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  The page number to retrieve. See [Classic pagination](/developer/api/classic-pagination).
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  The membership plans on this page.

  <Expandable title="membership plan properties">
    <ResponseField name="id" type="string<uuid>">
      The plan's unique identifier.
    </ResponseField>
    <ResponseField name="name" type="string">
      The plan's name.
    </ResponseField>
    <ResponseField name="description" type="string | null">
      The plan's description.
    </ResponseField>
    <ResponseField name="price" type="string | null">
      The price charged each billing period, in your store's currency, as a decimal string (for example `"29.00"`).
    </ResponseField>
    <ResponseField name="billing_interval" type="enum<string> | null">
      The billing period unit. One of `DAY`, `WEEK`, `MONTH`, `YEAR`.
    </ResponseField>
    <ResponseField name="billing_interval_count" type="integer">
      How many `billing_interval` units are in each billing period. For example `3` with `MONTH` bills every 3 months.
    </ResponseField>
    <ResponseField name="benefits_count" type="integer">
      The number of benefits on the plan.
    </ResponseField>
    <ResponseField name="created_at" type="string<date-time>">
      When the plan was created (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="meta properties">
    <ResponseField name="pagination" type="object">
      Pagination details. See [Classic pagination](/developer/api/classic-pagination).

      <Expandable title="pagination properties">
        <ResponseField name="current_page" type="integer">The page returned.</ResponseField>
        <ResponseField name="per_page" type="integer">The number of records per page.</ResponseField>
        <ResponseField name="total" type="integer">The total number of records.</ResponseField>
        <ResponseField name="last_page" type="integer">The number of the last page.</ResponseField>
        <ResponseField name="has_more" type="boolean">`true` if there are more pages after this one.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:customers`. |
| `429` | | You exceeded the [rate limit](/developer/api/rate-limits). |
