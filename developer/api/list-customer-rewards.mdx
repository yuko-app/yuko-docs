---
title: "List customer rewards"
api: "GET /public/customers/rewards"
description: "Retrieves a paginated list of discount codes issued to a customer, such as rewards redeemed with points."
---

Store credit redemptions don't create a customer reward; they appear as [points transactions](/developer/api/list-points-transactions) instead. Results are sorted by `created_at`, newest first.

<Info>Requires the `read:rewards` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="customer_id" type="string" required>
  The platform customer ID, for example the Shopify customer ID.
</ParamField>

<ParamField query="status" type="enum<string>">
  Return only rewards with this status. One of `active`, `used`, `inactive`, `expired`, `deleted`, `revert`.
</ParamField>

<ParamField query="per_page" type="integer" default={20}>
  The number of results per page. Must be between `1` and `100`.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  The page number to retrieve. See [Classic pagination](/developer/api/classic-pagination).
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  The customer rewards on this page.

  <Expandable title="customer reward properties">
    <ResponseField name="id" type="string<uuid>">
      Unique identifier for the customer reward.
    </ResponseField>
    <ResponseField name="customer_id" type="string<uuid>">
      Yuko's internal UUID for the customer this reward was issued to. This is not the platform customer ID you pass as `customer_id`.
    </ResponseField>
    <ResponseField name="reward_id" type="string<uuid> | null">
      The UUID of the record that issued this reward, such as the catalogue reward that was redeemed.
    </ResponseField>
    <ResponseField name="reward_type" type="string | null">
      The type of discount issued. For rewards redeemed with points, this is the catalogue reward's `reward_type`. `null` when no type was recorded. One of `fixed`, `percentage`, `free_shipping`, `free_product`, `pos_fixed`, `pos_percentage`.
    </ResponseField>
    <ResponseField name="status" type="enum<string>">
      The current status of this reward. One of `active`, `used`, `inactive`, `expired`, `deleted`, `revert`.
    </ResponseField>
    <ResponseField name="discount_code" type="string | null">
      The discount or coupon code issued to the customer.
    </ResponseField>
    <ResponseField name="points_used" type="integer">
      The number of loyalty points spent to generate this reward.
    </ResponseField>
    <ResponseField name="expires_at" type="string<date-time> | null">
      When this reward expires. `null` if it doesn't expire.
    </ResponseField>
    <ResponseField name="used_at" type="string<date-time> | null">
      When the reward was used. `null` if not yet used.
    </ResponseField>
    <ResponseField name="created_at" type="string<date-time>">
      When the reward was issued.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="meta properties">
    <ResponseField name="pagination" type="object">
      Pagination details. See [Classic pagination](/developer/api/classic-pagination).

      <Expandable title="pagination properties">
        <ResponseField name="current_page" type="integer">The page returned.</ResponseField>
        <ResponseField name="per_page" type="integer">The number of records per page.</ResponseField>
        <ResponseField name="total" type="integer">The total number of records.</ResponseField>
        <ResponseField name="last_page" type="integer">The number of the last page.</ResponseField>
        <ResponseField name="has_more" type="boolean">`true` if there are more pages after this one.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:rewards`. |
| `404` | `not_found` | No customer matches `customer_id` (`Customer not found`). |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://api.yukoapp.com/api/v1/public/customers/rewards?customer_id=9049402769586&status=active&per_page=20" \
  --header "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```javascript JavaScript
const customerId = "9049402769586";
const params = new URLSearchParams({ status: "active", per_page: 20 });

const response = await fetch(
  `https://api.yukoapp.com/api/v1/public/customers/rewards?customer_id=${customerId}&${params}`,
  {
    method: "GET",
    headers: {
      Authorization: "Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    },
  }
);

const data = await response.json();
```

```php PHP
$customerId = "9049402769586";
$query = http_build_query(["status" => "active", "per_page" => 20]);

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api.yukoapp.com/api/v1/public/customers/rewards?customer_id={$customerId}&{$query}");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
```

</RequestExample>
