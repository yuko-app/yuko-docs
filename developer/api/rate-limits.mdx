---
title: "Rate Limits"
---

To ensure platform stability and efficient processing for everyone, all of our API endpoints are rate limited.

Each API key can make up to 10 requests per second. Once this limit is reached, further requests return an `HTTP 429 - Too Many Requests` error.

Every response includes `X-RateLimit-Limit` and `X-RateLimit-Remaining` headers. A `429` response also includes a `Retry-After` header with the number of seconds to wait, and its body is:

```json
{
  "message": "Too Many Attempts."
}
```

After one second has elapsed, the key's limit resets and additional requests respond normally. Use techniques like caching, limiting the number of requests you make, and retries with backoff to stay within the limit.
