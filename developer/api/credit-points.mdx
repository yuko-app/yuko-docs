---
title: "Credit points"
api: "POST /public/customers/points/credit"
description: "Adds points to a customer's balance."
---

Use this to award points for something that happens outside Yuko, or to move balances over from another loyalty program. The points are added straight away and recorded in the customer's [activities](/developer/api/list-customer-activities) as a `point_adjustment` with your `description`. To award points for a repeatable action with a per-customer limit, use [Credit points for a custom action](/developer/api/credit-points-for-custom-action) instead.

<Info>Requires the `write:transactions` scope. See [Scopes](/developer/api/scopes).</Info>

## Body parameters

<ParamField body="identifier" type="string" required>
  The customer to credit. Accepts the Shopify customer ID, Yuko's customer `id` (a UUID), the customer's email address or their phone number. See [Identifying customers](/create-or-update-a-customer-identity#identifying-customers).
</ParamField>

<ParamField body="points" type="integer" required>
  The number of points to add. Must be `1` or more.
</ParamField>

<ParamField body="description" type="string" required>
  The reason for the credit, up to 255 characters. It's shown in the customer's activity log.
</ParamField>

<ParamField body="expires_at" type="integer">
  When these points expire, as a Unix timestamp in seconds or milliseconds. Must be in the future. Leave it out for points that don't expire.
</ParamField>

## Response

Returns `201 Created`.

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="transaction_id" type="string<uuid>">
      The ID of the new points transaction.
    </ResponseField>
    <ResponseField name="customer_id" type="string">
      The customer's Shopify customer ID (`platform_customer_id`).
    </ResponseField>
    <ResponseField name="points" type="integer">
      The number of points added.
    </ResponseField>
    <ResponseField name="type" type="string">
      Always `credit`.
    </ResponseField>
    <ResponseField name="expires_at" type="integer | null">
      When the points expire, as a Unix timestamp in seconds. `null` if they don't expire.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `write:transactions`. |
| `404` | `not_found` | No customer matches `identifier`. Message: "Customer not found". |
| `422` | `validation_error` | A body parameter is missing or invalid, for example `points` is below `1` or `expires_at` isn't in the future. |
| `422` | `adjustment_failed` | The customer is excluded from the loyalty program. Message: "Customer is banned". |
| `429` | | You exceeded the [rate limit](/developer/api/rate-limits). |

const response = await fetch(

    "Content-Type: application/json",

curl_close($ch);

$data = json_decode($response, true);
