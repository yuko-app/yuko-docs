---
title: "Create a points transaction"
api: "POST /public/customers/transactions"
description: "Adds or removes points from a customer's balance."
---

Pass a positive `points` value to credit points, or a negative value to debit them. The transaction is recorded with `action_type` `point_adjustment` and `source` `rest_api`. Points credited through the API don't expire.

<Info>Requires the `write:transactions` scope. See [Scopes](/developer/api/scopes).</Info>

## Body parameters

<ParamField body="customer_id" type="string" required>
  The platform customer ID, for example the Shopify customer ID.
</ParamField>

<ParamField body="points" type="integer" required>
  The number of points to add or remove. Use a positive value to credit points and a negative value to debit them. Can't be zero.
</ParamField>

<ParamField body="description" type="string" required>
  A human-readable reason for the adjustment, up to 255 characters. It's returned as `description` when you [list points transactions](/developer/api/list-points-transactions).
</ParamField>

## Response

Returns `201 Created` when the points transaction is created.

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="transaction_id" type="string<uuid>">
      The UUID of the newly created transaction.
    </ResponseField>
    <ResponseField name="customer_id" type="string">
      The platform customer ID of the customer whose balance was adjusted.
    </ResponseField>
    <ResponseField name="points" type="integer">
      The points value as submitted (positive for credit, negative for debit).
    </ResponseField>
    <ResponseField name="type" type="enum<string>">
      Whether the transaction was a credit or debit. One of `credit`, `debit`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `write:transactions`. |
| `404` | `not_found` | No customer matches `customer_id` (`Customer not found`). |
| `422` | `validation_error` | A body parameter is missing or invalid. |
| `422` | `adjustment_failed` | A debit is larger than the customer's current points balance (`Insufficient point balance`). |
| `422` | `adjustment_failed` | The customer is banned (`Customer is banned`). |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |

```bash cURL
curl --request POST \
  --url "https://api.yukoapp.com/api/v1/public/customers/transactions" \
  --header "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --header "Content-Type: application/json" \
  --data '{
    "customer_id": "9049402769586",
    "points": 100,
    "description": "Bonus points for completing a survey"
  }'
```

```javascript JavaScript
const customerId = "9049402769586";

const response = await fetch(
  `https://api.yukoapp.com/api/v1/public/customers/transactions`,
  {
    method: "POST",
    headers: {
      Authorization: "Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",

    },

      customer_id: customerId,
      points: 100,
      description: "Bonus points for completing a survey",
    }),
  }
);

const data = await response.json();
```

```php PHP
$customerId = "9049402769586";
$payload = json_encode([
    "customer_id" => $customerId,
    "points" => 100,
    "description" => "Bonus points for completing a survey",
]);

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api.yukoapp.com/api/v1/public/customers/transactions");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $payload);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "Content-Type: application/json",
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
```
