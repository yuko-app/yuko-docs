---
title: "Get customer balance"
api: "GET /public/customers/balance"
description: "Returns a customer's current loyalty points balance, including total earned and redeemed."
---

To get the balance along with tier and membership details, use [Get customer membership](/developer/api/list-memberships).

<Info>Requires the `read:customers` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="customer_id" type="string" required>
  The platform customer ID (for example, the Shopify customer ID). If you leave it out, this endpoint returns a `500` `internal_error` rather than a `422` validation error, so always send it.
</ParamField>

## Response

<ResponseField name="data" type="object">
  The customer's points balance.

  <Expandable title="balance properties">
    <ResponseField name="customer_id" type="string">
      The platform customer ID.
    </ResponseField>
    <ResponseField name="balance" type="integer">
      The customer's current redeemable points balance. Always `0` for customers who are banned or excluded from the loyalty program by a customer tag.
    </ResponseField>
    <ResponseField name="earned" type="integer">
      Total loyalty points ever earned by the customer.
    </ResponseField>
    <ResponseField name="redeemed" type="integer">
      Total points the customer has redeemed.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:customers`. |
| `404` | `not_found` | No customer matches `customer_id`. Message: "Customer not found". |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |
| `500` | `internal_error` | `customer_id` was left out. Message: "An unexpected error occurred. Please try again later." |
