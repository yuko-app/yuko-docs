---
title: "Classic pagination"
---

With classic pagination, a collection of records is broken down into pages which are returned one at a time.

List endpoints accept a `per_page` query parameter (default: `20`, maximum: `100`) that sets how many records are included in each page of results.

To move between pages, increment the `page` query parameter with each request. If you don't pass `page`, you get the first page of results.

Paginated responses include a `meta.pagination` object:

| Field | Description |
| :---- | :---------- |
| `current_page` | The page returned. |
| `per_page` | The number of records per page. |
| `total` | The total number of records. |
| `last_page` | The number of the last page. |
| `has_more` | `true` if there are more pages after this one. |
