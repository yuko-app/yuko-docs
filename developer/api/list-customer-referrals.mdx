---
title: "List customer referrals"
api: "GET /public/customers/referrals"
description: "Retrieves a paginated list of referral transactions where the customer was the advocate, newest first."
---

The advocate is the person who made the referral. Results are sorted by `created_at`, newest first.

<Note>If the customer has no referral code yet (no advocate record), the response is `{"data": []}` with no `meta` object.</Note>

<Info>Requires the `read:referrals` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="customer_id" type="string" required>
  The platform customer ID (for example, the Shopify customer ID).
</ParamField>

<ParamField query="status" type="enum<string>">
  Return only referrals with this status. One of `pending`, `rewarded`, `cancelled`, `expired`, `fraudulent`.
</ParamField>

<ParamField query="per_page" type="integer" default={20}>
  The number of results per page. Must be between `1` and `100`.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  The page number to retrieve. See [Classic pagination](/developer/api/classic-pagination).
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  The referral transactions on this page.

  <Expandable title="referral properties">
    <ResponseField name="id" type="string<uuid>">
      Unique identifier for the referral transaction.
    </ResponseField>
    <ResponseField name="advocate_id" type="string<uuid>">
      The UUID of the referral advocate record for this customer.
    </ResponseField>
    <ResponseField name="friend_customer_id" type="string<uuid>">
      Yuko's internal UUID for the friend who was referred. A referral is only recorded once the friend has a customer record, so this is always set.
    </ResponseField>
    <ResponseField name="order_id" type="string<uuid> | null">
      Yuko's internal UUID for the friend's qualifying order. `null` until the friend places a qualifying order.
    </ResponseField>
    <ResponseField name="referral_code" type="string | null">
      Intended to hold the referral code the friend used. Currently always `null`; use `referral_code` from [Retrieve a customer](/developer/api/retrieve-a-customer) to get the advocate's code.
    </ResponseField>
    <ResponseField name="status" type="enum<string>">
      The current status of the referral transaction. One of `pending`, `rewarded`, `cancelled`, `expired`, `fraudulent`.
    </ResponseField>
    <ResponseField name="created_at" type="string<date-time>">
      When the referral transaction was created (ISO 8601).
    </ResponseField>
    <ResponseField name="updated_at" type="string<date-time>">
      When the referral transaction was last updated (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="meta properties">
    <ResponseField name="pagination" type="object">
      Pagination details. See [Classic pagination](/developer/api/classic-pagination).

      <Expandable title="pagination properties">
        <ResponseField name="current_page" type="integer">The page returned.</ResponseField>
        <ResponseField name="per_page" type="integer">The number of records per page.</ResponseField>
        <ResponseField name="total" type="integer">The total number of records.</ResponseField>
        <ResponseField name="last_page" type="integer">The number of the last page.</ResponseField>
        <ResponseField name="has_more" type="boolean">`true` if there are more pages after this one.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:referrals`. |
| `404` | `not_found` | No customer matches `customer_id`. Message: "Customer not found". |
| `422` | `validation_error` | `status` isn't one of the allowed values. Message: "The selected status is invalid." |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |
