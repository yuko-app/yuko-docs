---
title: "List earning rules"
---

Retrieves a paginated list of active earning rules (Ways to earn) for your organisation. Results are sorted by `created_at` in descending order.

**GET /public/earning-rules**

#### **Authorizations**

**Authorization**

**string**

**header**

**required**

Bearer authentication header of the form `Bearer <token>`, where `<token>` is your REST API token.

#### **Required Scope**

**`read:earning_rules`**

This endpoint requires the `earning_rules` scope with **Read Access**. Configure key scopes in **Shopify admin → Apps → Yuko Loyalty → Integrations → REST API**. See [Scopes](/developer/api/scopes).

#### **Query Parameters**

**per_page**

**integer**

**default: 20**

The number of results per page. Values above `100` are capped at `100`.

Required range: `1 <= x <= 100`

**page**

**integer**

**default: 1**

The page number to retrieve.

#### **Response**

**200 - application/json**

**data**

**object[]**

Hide child attributes

**data.id**

**string\<uuid\>**

Unique UUID identifier for the earning rule.

Example:

`"a1b2c3d4-e5f6-7890-abcd-ef1234567890"`

**data.name**

**string**

The display name of the earning rule.

Example:

`"Place an order"`

**data.description**

**string | null**

A short description shown to customers.

Example:

`"Earn 5 points for every $1 spent."`

**data.campaign_type**

**null**

Currently always `null`. The API doesn't expose the earn rule's trigger (purchase, signup and so on); use `name` and `earning_rule` to identify the rule.

Example:

`null`

**data.earning_rule**

**object | null**

How points are calculated when the rule triggers. Keys vary by rule type. Common keys:

- `type`: what the rule awards, for example `points`.
- `method`: `fixed` (a set amount each time) or `increment` (an amount per unit of spend, purchase rules only).
- `earn_value`: the points awarded.
- `earn_from_amount`: for `increment`, the spend amount that earns `earn_value` points.
- `is_expire_enabled`, `expire_after`, `expire_period`: points expiry settings, if turned on.
- `url`: for social follow/like rules, the handle or page the customer is asked to visit.

Example:

`{ "type": "points", "method": "increment", "earn_value": 5, "earn_from_amount": 1 }`

**data.conditions**

**array | null**

Optional conditions that limit when the rule applies, such as product, collection or customer restrictions.

Example:

`null`

**data.is_active**

**boolean**

Whether this earning rule is currently active. Only active rules are returned, so this is always `true`.

Example:

`true`

**data.starts_at**

**null**

Currently always `null`.

**data.ends_at**

**null**

Currently always `null`.

**data.created_at**

**string\<date-time\>**

Example:

`"2026-01-10T09:00:00+00:00"`

**meta**

**object**

Hide child attributes

**meta.pagination**

**object**

Hide child attributes

**meta.pagination.current_page**

**integer**

Example:

`1`

**meta.pagination.per_page**

**integer**

Example:

`20`

**meta.pagination.total**

**integer**

Example:

`4`

**meta.pagination.last_page**

**integer**

Example:

`1`

**meta.pagination.has_more**

**boolean**

Example:

`false`

```bash cURL
curl --request GET \
  --url "https://api.yukoapp.com/api/v1/public/earning-rules?per_page=20" \
  --header "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```javascript JavaScript
const params = new URLSearchParams({ per_page: 20 });

const response = await fetch(
  `https://api.yukoapp.com/api/v1/public/earning-rules?${params}`,
  {
    method: "GET",
    headers: {
      Authorization: "Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    },
  }
);

const data = await response.json();
```

```php PHP
$query = http_build_query(["per_page" => 20]);

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api.yukoapp.com/api/v1/public/earning-rules?{$query}");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
```
