---
title: "List earning rules"
api: "GET /public/earning-rules"
description: "Retrieves a paginated list of active earning rules (Ways to earn) for your store."
---

Results are sorted by `created_at`, newest first. Only active rules are returned, including rules marked **Hide from on-site displays** and [Custom Action](/developer/api/credit-points-for-custom-action) rules. A Custom Action rule's `id` is the `campaign` you pass to [Credit points for a custom action](/developer/api/credit-points-for-custom-action).

<Info>Requires the `read:earning_rules` scope. See [Scopes](/developer/api/scopes).</Info>

## Query parameters

<ParamField query="per_page" type="integer" default={20}>
  The number of results per page. Values above `100` are treated as `100`.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  The page number to retrieve. See [Classic pagination](/developer/api/classic-pagination).
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  The earning rules on this page.

  <Expandable title="earning rule properties">
    <ResponseField name="id" type="string<uuid>">
      Unique UUID identifier for the earning rule.
    </ResponseField>
    <ResponseField name="name" type="string">
      The rule's display name, with placeholders such as `[earn_value]`, `[earn_from_amount]` and `[points_label]` filled in.
    </ResponseField>
    <ResponseField name="name_template" type="string">
      The rule's name exactly as saved in Yuko, with placeholders left in.
    </ResponseField>
    <ResponseField name="description" type="string | null">
      The description shown to customers, with placeholders filled in.
    </ResponseField>
    <ResponseField name="description_template" type="string | null">
      The description exactly as saved in Yuko, with placeholders left in.
    </ResponseField>
    <ResponseField name="campaign_type" type="null">
      Currently always `null`. The API doesn't expose the earn rule's trigger (purchase, signup and so on); use `name` and `earning_rule` to identify the rule.
    </ResponseField>
    <ResponseField name="earning_rule" type="object | null">
      How points are calculated when the rule triggers. Keys vary by rule type. Common keys:

      - `type`: what the rule awards, for example `points`.
      - `method`: `fixed` (a set amount each time) or `increment` (an amount per unit of spend, purchase rules only).
      - `earn_value`: the points awarded.
      - `earn_from_amount`: for `increment`, the spend amount that earns `earn_value` points.
      - `is_expire_enabled`, `expire_after`, `expire_period`: points expiry settings, if turned on.
      - `url`: for social follow/like rules, the handle or page the customer is asked to visit.
      - `limit_interval`, `limit_count`, `limit_year_method`: for Custom Action rules, how many times (`limit_count`) a customer can earn per period (`limit_interval`: `none`, `daily`, `weekly`, `monthly` or `yearly`). For yearly limits, `limit_year_method` is `rolling` (the last 365 days) or `calendar`.
    </ResponseField>
    <ResponseField name="conditions" type="array | null">
      Optional conditions that limit when the rule applies, such as product, collection or customer restrictions.
    </ResponseField>
    <ResponseField name="is_active" type="boolean">
      Whether this earning rule is currently active. Only active rules are returned, so this is always `true`.
    </ResponseField>
    <ResponseField name="starts_at" type="null">
      Currently always `null`.
    </ResponseField>
    <ResponseField name="ends_at" type="null">
      Currently always `null`.
    </ResponseField>
    <ResponseField name="created_at" type="string<date-time>">
      When the earning rule was created (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="meta properties">
    <ResponseField name="pagination" type="object">
      Pagination details. See [Classic pagination](/developer/api/classic-pagination).

      <Expandable title="pagination properties">
        <ResponseField name="current_page" type="integer">The page returned.</ResponseField>
        <ResponseField name="per_page" type="integer">The number of records per page.</ResponseField>
        <ResponseField name="total" type="integer">The total number of records.</ResponseField>
        <ResponseField name="last_page" type="integer">The number of the last page.</ResponseField>
        <ResponseField name="has_more" type="boolean">`true` if there are more pages after this one.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:earning_rules`. |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |

    },

$query = http_build_query(["per_page" => 20]);
