---
title: "List VIP tiers"
api: "GET /public/tiers"
description: "Retrieves all VIP tiers configured for your organisation, with their benefits."
---

Tiers are sorted by `threshold_value` in ascending order. Each tier includes its associated benefits.

<Info>Requires the `read:tiers` scope. See [Scopes](/developer/api/scopes).</Info>

## Response

<ResponseField name="data" type="object[]">
  The VIP tiers, lowest threshold first.

  <Expandable title="tier properties">
    <ResponseField name="id" type="string<uuid>">
      Unique UUID identifier for the VIP tier.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the VIP tier.
    </ResponseField>
    <ResponseField name="threshold_value" type="integer">
      The value a customer must reach to qualify for this tier, measured in the program's tier metric: amount spent (default), points earned or orders placed, as configured in your VIP settings.
    </ResponseField>
    <ResponseField name="multiplier" type="number">
      The points earning multiplier applied to customers in this tier.
    </ResponseField>
    <ResponseField name="icon" type="object | null">
      The tier icon, or `null` if none is set. Always has four keys: `source` (`default` or `custom`), `slug` (built-in icons, otherwise `null`), `id` (custom uploads, otherwise `null`) and `url` (the custom upload URL, or the hosted SVG for a built-in icon).
    </ResponseField>
    <ResponseField name="benefits" type="object[]">
      A list of benefits associated with this tier.

      <Expandable title="benefit properties">
        <ResponseField name="name" type="string">
          The display name of the benefit.
        </ResponseField>
        <ResponseField name="benefit_type" type="enum<string>">
          The type of benefit issued to the customer. One of `fixed`, `percentage`, `free_product`, `free_shipping`, `bonus_points`, `store_credit`, `custom`.
        </ResponseField>
        <ResponseField name="benefit_value" type="object">
          The stored value configuration for this benefit, returned as-is. Structure varies by `benefit_type`. For example, `fixed`/`percentage` benefits include `reward_type`, `method` (`automatic` or `one_time`), `discount_value`, `coupon_prefix` and `min_requirement`; `bonus_points` and `store_credit` include `method`, `reward_type` and `discount_value`; `custom` benefits may be empty.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="string<date-time> | null">
      When the tier was created (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `read:tiers`. |
| `429` | | The key exceeded the [rate limit](/developer/api/rate-limits). |
