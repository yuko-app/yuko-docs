---
title: "Debit points"
api: "POST /public/customers/points/debit"
description: "Deducts a reward's points cost from a customer's balance."
---

Use this when your own system gives the customer a reward from your Yuko catalogue, for example in a custom checkout or app. Yuko deducts the reward's points cost and records the redemption in the customer's [activities](/developer/api/list-customer-activities) as "Redeemed reward: *reward name*".

<Warning>Yuko only deducts the points. It doesn't create a discount code or store credit, so your system is responsible for giving the customer the reward.</Warning>

The reward must be an active online reward from [List rewards](/developer/api/list-rewards). Shopify POS rewards can't be used. Points are taken from the customer's oldest points first.

<Info>Requires the `write:transactions` scope. See [Scopes](/developer/api/scopes).</Info>

## Body parameters

<ParamField body="identifier" type="string" required>
  The customer to debit. Accepts the Shopify customer ID, Yuko's customer `id` (a UUID), the customer's email address or their phone number. See [Identifying customers](/create-or-update-a-customer-identity#identifying-customers).
</ParamField>

<ParamField body="reward_id" type="string<uuid>" required>
  The `id` of the reward from [List rewards](/developer/api/list-rewards). The reward's `points_cost` is deducted.
</ParamField>

## Response

Returns `201 Created`.

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="transaction_id" type="string<uuid>">
      The ID of the new points transaction.
    </ResponseField>
    <ResponseField name="customer_id" type="string">
      The customer's Shopify customer ID (`platform_customer_id`).
    </ResponseField>
    <ResponseField name="reward_id" type="string<uuid>">
      The reward that was redeemed.
    </ResponseField>
    <ResponseField name="points" type="integer">
      The number of points deducted (the reward's points cost).
    </ResponseField>
    <ResponseField name="type" type="string">
      Always `debit`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `write:transactions`. |
| `404` | `not_found` | No customer matches `identifier` ("Customer not found"), or `reward_id` isn't an active online reward ("Reward not found"). |
| `422` | `validation_error` | `identifier` or `reward_id` is missing, or `reward_id` isn't a UUID. |
| `422` | `adjustment_failed` | The points couldn't be deducted. Messages: "Insufficient point balance", "Customer is banned", "This reward has no points cost.", or "Another points update is in progress. Please try again." |
| `429` | | You exceeded the [rate limit](/developer/api/rate-limits). |

<RequestExample>

```bash cURL
curl --request POST \
  --url "https://api.yukoapp.com/api/v1/public/customers/points/debit" \
  --header "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --header "Accept: application/json" \
  --header "Content-Type: application/json" \
  --data '{
    "identifier": "jane.smith@example.com",
    "reward_id": "b2c3d4e5-f6a7-4901-8cde-f12345678901"
  }'
```

```javascript JavaScript
const response = await fetch(
  "https://api.yukoapp.com/api/v1/public/customers/points/debit",
  {
    method: "POST",
    headers: {
      Authorization: "Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      Accept: "application/json",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      identifier: "jane.smith@example.com",
      reward_id: "b2c3d4e5-f6a7-4901-8cde-f12345678901",
    }),
  }
);

const data = await response.json();
```

```php PHP
$payload = json_encode([
    "identifier" => "jane.smith@example.com",
    "reward_id" => "b2c3d4e5-f6a7-4901-8cde-f12345678901",
]);

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api.yukoapp.com/api/v1/public/customers/points/debit");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $payload);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Authorization: Bearer py_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "Accept: application/json",
    "Content-Type: application/json",
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
```

</RequestExample>
