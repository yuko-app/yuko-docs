---
title: "Credit points for a custom action"
api: "POST /public/customers/points/credit/{campaign}"
description: "Awards a customer the points set on a Custom Action earn rule."
---

A **Custom Action** is a way to earn that you define in Yuko, such as *Complete a survey* or *Attend an event*. You set the points, an optional limit on how often each customer can earn them, and an optional expiry. Call this endpoint each time a customer completes the action, and Yuko awards the points by the rule's settings.

To set one up, go to **Shopify admin → Apps → Yuko Loyalty → Loyalty → Programs → Ways to earn → Add another way → Custom Action**. After you save it, the **REST API** card on the rule shows the full URL to call, including its `campaign` ID.

<Info>Requires the `write:transactions` scope. Custom actions are available on paid plans. See [Scopes](/developer/api/scopes).</Info>

## Path parameters

<ParamField path="campaign" type="string<uuid>" required>
  The ID of the Custom Action earn rule. Copy it from the **REST API** card on the rule, or use the rule's `id` from [List ways to earn](/developer/api/list-ways-to-earn).
</ParamField>

## Body parameters

<ParamField body="identifier" type="string" required>
  The customer who completed the action. Accepts the Shopify customer ID, Yuko's customer `id` (a UUID), the customer's email address or their phone number. See [Identifying customers](/create-or-update-a-customer-identity#identifying-customers).
</ParamField>

## Response

Returns `201 Created`.

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="campaign_id" type="string<uuid>">
      The Custom Action earn rule that was credited.
    </ResponseField>
    <ResponseField name="customer_id" type="string">
      The customer's Shopify customer ID (`platform_customer_id`).
    </ResponseField>
    <ResponseField name="points" type="integer">
      The number of points awarded, including the customer's VIP tier multiplier if the rule uses tier multipliers.
    </ResponseField>
    <ResponseField name="status" type="string | null">
      The status of the points: `active` when they can be spent now, or `on_hold` when they're held before being released.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
| :----- | :--- | :--- |
| `401` | `missing_token`, `invalid_token` | The API key is missing, wrong or revoked. |
| `403` | `insufficient_scope` | The key doesn't have `write:transactions`. |
| `403` | `plan_upgrade_required` | The store's plan doesn't include custom actions. Message: "Custom actions are available on paid plans." |
| `404` | `not_found` | `campaign` isn't a Custom Action earn rule in this store ("Custom action not found"), or no customer matches `identifier` ("Customer not found"). |
| `422` | `validation_error` | `identifier` is missing. |
| `422` | `action_inactive` | The earn rule is turned off. Message: "This custom action is not active." |
| `422` | `limit_reached` | The customer has already earned the maximum number of times in the rule's limit period. Message: "This customer has reached the earning limit for this action." |
| `422` | `credit_failed` | No points could be awarded, for example because the customer is excluded from the loyalty program. |
| `429` | | You exceeded the [rate limit](/developer/api/rate-limits). |
